C Programming Cheat Sheet

Data types, pointers, arrays, structs, and manual memory management – the fundamentals that everything else in systems programming is built on.

Quick reference C (C99 / C11) Programming / Systems
Data Types Operators Control Flow Functions Pointers Arrays & Strings Structs & Unions Memory Management File I/O Preprocessor Tips & Mistakes

01.Data Types 10

int
Signed whole number, typically 4 bytes.
short / long / long long
Smaller and larger integer variants (sizes are platform-dependent).
unsigned int
Non-negative integers only – doubles the positive range.
float / double
Single- and double-precision floating point (4 and 8 bytes).
char
A single byte, usually an ASCII character.
_Bool / bool
Boolean type; bool is available via <stdbool.h>.
void
No value – used for functions that return nothing, or generic pointers.
size_t
Unsigned type returned by sizeof, used for sizes and indices.
int32_t / uint8_t...
Fixed-width integer types from <stdint.h> – portable, exact sizes.
const
Qualifier marking a variable as read-only after initialization.

02.Operators 6 groups

+ − * / %
Arithmetic; % is modulo (integer remainder only).
== != > < >= <=
Relational comparisons, result in 0 or 1.
&& || !
Logical AND, OR, NOT – short-circuit evaluated.
& | ^ ~ << >>
Bitwise AND, OR, XOR, NOT, left/right shift.
= += -= *= /=
Assignment and compound assignment.
++ / --
Increment/decrement; prefix (++x) vs. postfix (x++) differ in the value of the expression itself.

03.Control Flow

c — control_flow 
/* if / else if / else */
if (x > 0) {
    printf("positive\n");
} else if (x == 0) {
    printf("zero\n");
} else {
    printf("negative\n");
}

/* for loop */
for (int i = 0; i < 10; i++) {
    printf("%d\n", i);
}

/* while / do-while */
while (x < 10) { x++; }
do { x++; } while (x < 10);   /* body runs at least once */

/* switch */
switch (x) {
    case 1:
        printf("one\n");
        break;              /* required, or execution falls through */
    case 2:
        printf("two\n");
        break;
    default:
        printf("other\n");
}

04.Functions

c — function_basics 
/* declaration (prototype) — usually in a header */
int add(int a, int b);

/* definition */
int add(int a, int b) {
    return a + b;
}

/* passing a pointer lets a function modify the caller's variable */
void increment(int *x) {
    (*x)++;
}

int main(void) {
    int n = 5;
    increment(&n);       /* pass the address of n */
    printf("%d\n", n);   /* 6 */
    return 0;
}

C passes arguments by value – a function only ever sees a copy. To let a function modify a caller's variable, pass a pointer to it instead.

05.Pointers 8

int *p;
Declares p as a pointer to an int.
p = &x;
& is the address-of operator – p now holds x's address.
*p
The dereference operator – accesses the value p points to.
int **pp;
A pointer to a pointer – common for modifying a pointer inside a function.
void *p;
A generic pointer that can hold the address of any type; must be cast before dereferencing.
NULL
A pointer value guaranteed not to point to any valid object.
p + 1
Pointer arithmetic – advances by sizeof(*p) bytes, not one byte.
const int *p
Pointer to a const int – the pointed-to value can't be modified through p.

06.Arrays & Strings

c — arrays_and_strings 
int nums[5] = {1, 2, 3, 4, 5};
int len = sizeof(nums) / sizeof(nums[0]);  /* element count */

/* arrays decay to a pointer to their first element when passed to a function */
void printArray(int *arr, int len) {
    for (int i = 0; i < len; i++) printf("%d ", arr[i]);
}

/* strings are just char arrays, null-terminated with '\0' */
char name[20] = "hello";
printf("%s has length %zu\n", name, strlen(name));

strcpy(dest, src);      /* copy — unsafe if dest is too small */
strncpy(dest, src, n);  /* bounded copy — safer, may not null-terminate */
strcat(dest, src);      /* append */
strcmp(a, b);           /* returns 0 if equal */

07.Structs & Unions

c — structs 
typedef struct {
    char name[32];
    int age;
} Person;

Person p1 = {"Alice", 30};
Person *pp = &p1;

printf("%s\n", p1.name);    /* dot operator on a struct value */
printf("%s\n", pp->name);   /* arrow operator on a struct pointer */

/* a union shares one block of memory between its members —
   only one member is valid at a time */
union Data {
    int i;
    float f;
};

08.Manual Memory Management

malloc(n)
Allocates n bytes on the heap, uninitialized. Returns NULL on failure.
calloc(n, size)
Allocates and zero-initializes n elements of size bytes each.
realloc(p, n)
Resizes a previous allocation, possibly moving it – always reassign the return value.
free(p)
Releases heap memory back to the system. Must be called exactly once per allocation.
c — heap_allocation 
int *arr = malloc(10 * sizeof(int));
if (arr == NULL) {
    fprintf(stderr, "allocation failed\n");
    return 1;
}

/* ... use arr ... */

free(arr);
arr = NULL;   /* avoid an accidental use-after-free */

09.File I/O

c — file_io 
FILE *f = fopen("data.txt", "r");
if (f == NULL) {
    perror("fopen failed");
    return 1;
}

char line[256];
while (fgets(line, sizeof(line), f) != NULL) {
    printf("%s", line);
}
fclose(f);

/* writing */
FILE *out = fopen("out.txt", "w");
fprintf(out, "value: %d\n", 42);
fclose(out);

10.Preprocessor Directives 6

#include <stdio.h>
Pulls in a standard library header.
#include "myheader.h"
Includes a local project header.
#define MAX 100
A text-substitution constant, replaced before compilation.
#define SQ(x) ((x)*(x))
A macro function – always parenthesize both the macro and its arguments.
#ifndef / #define / #endif
An include guard, preventing a header from being processed twice.
#pragma once
A non-standard but widely supported alternative to include guards.

11.Tips & Common Mistakes

Every malloc needs a free:if a heap allocation goes out of scope without being freed, that memory is leaked for the life of the program. Tools like Valgrind can catch leaks and invalid accesses during testing.
Format specifiers must match:%d for int, %f for float/double, %s for a string, %p for a pointer, %zu for size_t. A mismatched specifier is undefined behavior, not a compile error.
Common mistake — buffer overflow:strcpy and gets don't check destination size. Prefer strncpy, snprintf, or fgets, and always account for the null terminator.
Common mistake — dangling and use-after-free:a pointer left holding an address after free() is dangling – dereferencing it is undefined behavior. Set the pointer to NULL immediately after freeing it.
Common mistake — = vs. ==:if (x = 5) assigns 5 to x and is always true, instead of comparing x to 5. Most compilers warn about this with -Wall; treat that warning as an error.
