Install Naabu on Kali Linux

Method 1 — Kali APT (recommended)
terminal 
sudo apt update
sudo apt install naabu -y
naabu -version
Method 2 — Go install (latest)
terminal 
go install -v github.com/projectdiscovery/naabu/v2/cmd/naabu@latest
sudo mv ~/go/bin/naabu /usr/local/bin/
Method 3 — Binary from GitHub releases
terminal 
wget https://github.com/projectdiscovery/naabu/releases/download/v2.3.1/naabu_2.3.1_linux_amd64.zip
unzip naabu_2.3.1_linux_amd64.zip
sudo mv naabu /usr/local/bin/

Replace v2.3.1 with the latest version from the naabu releases page.

Tip:Nmap must also be installed for the -nmap / -nmap-cli integration flags: sudo apt install nmap -y

Run Your First Scan

terminal 
# Fast scan of the 100 most common ports (sudo = SYN mode)
sudo naabu -host 192.168.1.1 -top-ports 100

# Save the results to a file
sudo naabu -host 192.168.1.1 -top-ports 100 -o results.txt

# Output format is simply host:port, one per line:
# 192.168.1.1:22
# 192.168.1.1:80

Full Naabu Recon Workflow (Copy-Paste)

terminal 
# 1) Discover live hosts on the subnet
sudo naabu -host 192.168.1.0/24 -host-discovery -silent > live_hosts.txt

# 2) Scan the top 1000 ports on every live host
sudo naabu -l live_hosts.txt -top-ports 1000 -silent -o open_ports.txt

# 3) Fingerprint services automatically with nmap
sudo naabu -l live_hosts.txt -top-ports 100 -nmap -nmap-cli 'nmap -sV -sC -p {{port}} {{host}}'

# 4) Turn web ports into URLs and hunt CVEs with nuclei
grep -E ':(80|443|8080|8443)$' open_ports.txt | httpx -silent | nuclei -t cves/
Warning:Naabu's SYN scan needs root. Run it with sudo, and only against networks you are explicitly authorized to test.

FAQ — Naabu Port Scanner

Frequently Asked Questions

Quick answers to the most common questions about naabu on Kali Linux – how it compares to nmap and masscan, root requirements, legality, passive mode, CDN handling, and output.

What is Naabu?
Naabu is an open-source port scanning tool written in Go by ProjectDiscovery. It performs very fast SYN and connect scans, includes host discovery, CDN detection, passive Shodan-based enumeration, and built-in Nmap integration. It ships in the Kali Linux repositories and is a staple for fast reconnaissance.
Naabu vs Nmap – which should I use?
Use both. Naabu finds open ports at very high speed; Nmap fingerprints services, versions, and the OS, and runs script scans. Naabu's -nmap and -nmap-cli flags chain the two automatically – naabu discovers the ports, nmap deep-scans them.
Naabu vs Masscan – what's the difference?
Naabu is easier to install and use, with host discovery, CDN-aware scanning, passive Shodan mode, and pipeline-friendly host:port output. Masscan offers raw speed for internet-scale (0.0.0.0/0) surveys. Most testers prefer naabu for engagements and automation; masscan for full-internet research.
Does Naabu need root (sudo)?
Yes. The default SYN scan uses raw sockets, which requires root privileges – run it with sudo. Without root, naabu falls back to a full TCP connect scan that is slower and more detectable. Nmap must also be installed for the -nmap integration flags.
Is port scanning with Naabu legal?
Only on networks you own or have explicit written authorization to test. Unauthorized port scanning may violate computer fraud and abuse laws in most jurisdictions – see the legal disclaimer at the bottom of this page.
What does the -top-ports flag do?
Naabu maintains ranked lists of the most commonly open ports. -top-ports 100 scans only the top 100 ports (fast, broad coverage), while -top-ports 1000 goes deeper while still finishing quickly.
Can Naabu scan UDP ports?
No. Naabu focuses on TCP scanning. For UDP service discovery, run nmap -sU against the live hosts naabu finds.
How do I detect service versions with Naabu?
Naabu doesn't fingerprint services itself. Use the -nmap flag, or a custom command like -nmap-cli 'nmap -sV -p {{port}} {{host}}', so every discovered port is automatically scanned by nmap for version detection and scripts.
What is Naabu passive mode?
The -passive flag pulls historical port data from Shodan instead of sending any packets to the target – the stealthiest possible recon method. It requires your SHODAN_API_KEY environment variable to be set, and the data can be outdated, so confirm critical findings actively.
How do I deal with CDN or Cloudflare-protected targets?
Use -cdn to display which CDN a host sits behind, and -exclude-cdn to skip pointless full port scans of CDN edge IPs (those hosts only get 80/443 checked). This dramatically speeds up large scans and keeps results clean.
How do I read and save Naabu output?
Naabu prints results as host:port lines (e.g., 192.168.1.10:443). Save them with -o file.txt, use -json or -csv for structured output, and -stream to write results the moment they are discovered.
