x86-64 Assembly Language Cheat Sheet

Registers, addressing modes, the instructions you'll actually use, and the System V AMD64 calling convention – written in Intel syntax (NASM), the way you'd see it on Linux.

01.General-Purpose Registers 16 registers

x86-64 has sixteen 64-bit general-purpose registers. Each can be accessed as a 64-, 32-, 16-, or 8-bit value using a different name for the same physical register.

Callee-saved: the called function must preserve the original value before returning. Caller-saved: the calling function must save it itself if it needs the value after the call.

02.Memory Addressing Modes 5 forms

mov rax, 5
Immediate – a literal constant value.
mov rax, rbx
Register – direct register-to-register.
mov rax, [0x4010]
Direct – a fixed memory address.
mov rax, [rbx]
Register indirect – address held in a register.
mov rax, [rbx+rcx*4+8]
Base + index×scale + displacement – used for arrays and structs.
lea rax, [rbx+8]
Load Effective Address – computes the address but doesn't dereference it.

03.Data Movement 6 instructions

mov dst, src
Copies src into dst. The single most common instruction.
lea dst, [expr]
Loads a computed address into dst without reading memory – often used for fast arithmetic.
push src
Decrements rsp by 8, then stores src at the new top of the stack.
pop dst
Loads the value at the top of the stack into dst, then increments rsp by 8.
xchg a, b
Swaps the values of a and b.
movzx / movsx
Moves a smaller value into a larger register, zero- or sign-extending it.

04.Arithmetic & Logic 12 instructions

add dst, src
dst = dst + src
sub dst, src
dst = dst − src
inc / dec dst
Adds or subtracts 1 from dst.
imul dst, src
Signed multiply; dst = dst × src.
mul src
Unsigned multiply of rax by src; result in rdx:rax.
idiv src
Signed divide rdx:rax by src; quotient in rax, remainder in rdx.
neg dst
Two's-complement negation: dst = −dst.
and / or / xor
Bitwise AND, OR, and exclusive OR.
not dst
Bitwise complement (flips every bit).
shl / sal dst, n
Shift left by n bits (multiplies by 2n).
shr dst, n
Logical shift right by n bits (unsigned divide by 2n).
sar dst, n
Arithmetic shift right, preserving the sign bit.

05.Comparison & Control Flow 12 instructions

cmp a, b
Computes a − b and sets flags, without storing the result.
test a, b
Computes a AND b and sets flags, without storing the result – common for zero checks.
jmp label
Unconditional jump.
je / jz label
Jump if equal / zero flag set.
jne / jnz label
Jump if not equal / zero flag clear.
jg / jge label
Jump if greater / greater-or-equal (signed).
jl / jle label
Jump if less / less-or-equal (signed).
ja / jae label
Jump if above / above-or-equal (unsigned).
jb / jbe label
Jump if below / below-or-equal (unsigned).
loop label
Decrements rcx, jumps to label if rcx isn't zero.
call label
Pushes the return address, then jumps to label.
ret
Pops the return address off the stack and jumps to it.

06.Stack & Function Calls

The System V AMD64 calling convention (Linux, macOS) passes the first six integer/pointer arguments in registers, in this order, with any remaining arguments on the stack:

Argument Order
rdi, rsi, rdx, rcx, r8, r9
1st through 6th arguments. Return value comes back in rax (rdx:rax for 128-bit results).
nasm — function_prologue_epilogue 
; standard function prologue
push  rbp            ; save caller's base pointer
mov   rbp, rsp        ; establish new stack frame
sub   rsp, 32         ; reserve local stack space

; ... function body ...

; standard function epilogue
mov   rsp, rbp        ; deallocate local space
pop   rbp             ; restore caller's base pointer
ret                   ; return to caller

The stack grows downward: push subtracts from rsp, pop adds to it. Per the ABI, rsp must be 16-byte aligned immediately before a call instruction.

07.NASM Directives & Sections

section .text
Executable code goes here.
section .data
Initialized global/static data.
section .bss
Uninitialized data, zeroed at load time.
global _start
Exports a symbol so the linker/OS can find the entry point.
db / dw / dd / dq
Define byte / word (2B) / doubleword (4B) / quadword (8B) initialized data.
resb / resw / resd / resq
Reserve uninitialized byte / word / doubleword / quadword space in .bss.
equ
Defines a compile-time constant, e.g. SYS_WRITE equ 1.
%define / %macro
Preprocessor text substitution and reusable macros.

08.The Flags Register 6 common flags

ZF
Zero Flag – set when a result is zero.
SF
Sign Flag – set to the most significant bit of the result (1 = negative).
CF
Carry Flag – set on unsigned overflow or borrow.
OF
Overflow Flag – set on signed overflow.
PF
Parity Flag – set if the low byte of the result has an even number of set bits.
AF
Auxiliary Carry Flag – carry out of bit 3, used internally by BCD instructions.

09.Tips & Common Mistakes

Intel vs. AT&T syntax:this sheet uses Intel syntax (mov dst, src, no % or $ prefixes) as used by NASM and MASM. AT&T syntax, used by default in GNU tools, reverses operand order (mov src, dst) and prefixes registers with % and immediates with $.
mov vs. lea:mov rax, [rbx+8] reads the memory at that address into rax. lea rax, [rbx+8] computes the address itself and stores that in rax – no memory access happens at all.
Common mistake — idiv operand size:idiv divides the full rdx:rax pair, not just rax. Forgetting to zero or sign-extend rdx first (with cqo) before a 64-bit division produces a garbage quotient.
Common mistake — stack alignment:calling a function (especially libc functions) with rsp not 16-byte aligned is a frequent source of crashes that only show up with certain instructions, like movaps/SSE operations.
