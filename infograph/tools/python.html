Python Programming Cheat Sheet

Core syntax, data structures, comprehensions, OOP, and error handling – the Python you'll reach for in almost every script, written for Python 3.

01.Core Data Types 8 types

int
Whole numbers, arbitrary precision: x = 42
float
Decimal numbers: x = 3.14
bool
True / False – a subclass of int.
str
Immutable text: x = "hello"
list
Ordered, mutable: x = [1, 2, 3]
tuple
Ordered, immutable: x = (1, 2, 3)
dict
Key-value pairs: x = {"a": 1}
set
Unordered, unique values: x = {1, 2, 3}

02.String Methods & Formatting 10

.upper() / .lower()
Converts case.
.strip()
Removes leading/trailing whitespace (or given characters).
.split(sep)
Splits into a list on a separator (default: whitespace).
.join(iterable)
Joins an iterable of strings using this string as the separator.
.replace(old, new)
Returns a copy with all occurrences replaced.
.find(sub)
Returns the index of the first match, or −1 if not found.
.startswith() / .endswith()
Boolean prefix/suffix check.
.format() / f-strings
f"{name} is {age}" – the preferred formatting style.
.zfill(n) / :05d
Zero-pads a string, or a number inside an f-string.
slicing [a:b:c]
s[::-1] reverses a string; s[1:4] takes a substring.

03.Lists, Dicts & Sets 12

.append(x)
Adds x to the end of a list.
.extend(iter)
Appends every item from another iterable.
.insert(i, x)
Inserts x at index i.
.pop(i)
Removes and returns the item at index i (default: last).
.sort() / sorted()
In-place sort vs. returns a new sorted list.
list[::-1]
Reverses a list via slicing.
dict.get(k, default)
Returns the value for k, or default if missing – no KeyError.
dict.items()
Returns key-value pairs for iteration.
dict.setdefault(k, v)
Returns dict[k] if present, else sets it to v first.
set.union() / .intersection()
Combine or find common elements between sets.
set.difference()
Elements in one set but not the other.
zip(a, b)
Pairs up elements from two or more iterables.

04.Control Flow

python — control_flow 
# if / elif / else
if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")

# for loop over an iterable
for item in [1, 2, 3]:
    print(item)

# while loop
while x < 10:
    x += 1

# loop control
for i in range(10):
    if i == 5:
        break       # exit the loop
    if i % 2 == 0:
        continue    # skip to next iteration

05.Functions & Lambdas

def f(a, b=1):
Positional argument a, keyword argument b with a default.

Collects extra positional arguments into a tuple.

Collects extra keyword arguments into a dict.
lambda x: x*2
An anonymous, single-expression function.
*args, **kwargs at a call
Unpacks a list/tuple or dict into positional/keyword arguments.

Type hint for the return value (not enforced at runtime).

06.Comprehensions

[x*2 for x in nums]
List comprehension.
{x: x*2 for x in nums}
Dict comprehension.
{x*2 for x in nums}
Set comprehension.
(x*2 for x in nums)
Generator expression – lazy, doesn't build the full list in memory.
[x for x in nums if x>0]
Comprehension with a filter condition.
[x if x>0 else 0 for x in nums]
Comprehension with an inline conditional expression.

07.Object-Oriented Programming

python — class_basics 
class Animal:
    def __init__(self, name):
        self.name = name          # instance attribute

    def speak(self):
        return f"{self.name} makes a sound"

    def __str__(self):
        return f"Animal({self.name})"

class Dog(Animal):                 # inheritance
    def speak(self):               # method override
        return f"{self.name} barks"

d = Dog("Rex")
print(d.speak())                   # "Rex barks"
__init__(self, ...)
Constructor, called automatically on instantiation.
__str__ / __repr__
Human-readable vs. developer/debug string representation.
super().__init__()
Calls the parent class's constructor from a subclass.
@staticmethod
A method that doesn't receive self or cls.
@classmethod
A method that receives the class itself as cls, not an instance.
@property
Exposes a method as a read-only attribute.

08.Exception Handling

python — try_except 
try:
    result = 10 / x
except ZeroDivisionError:
    print("can't divide by zero")
except (TypeError, ValueError) as e:
    print(f"bad input: {e}")
else:
    print("ran only if no exception occurred")
finally:
    print("always runs, exception or not")

# raising your own exception
if x < 0:
    raise ValueError("x must be non-negative")

09.File I/O

python — file_io 
# reading a file
with open("data.txt", "r") as f:
    contents = f.read()        # whole file as one string
    # or: for line in f: ...

# writing a file
with open("out.txt", "w") as f:
    f.write("hello\n")

# appending
with open("out.txt", "a") as f:
    f.write("more text\n")

with guarantees the file is closed automatically, even if an exception is raised inside the block.

11.Tips & Common Mistakes

Mutable default arguments:never use a mutable object like a list or dict as a default argument – it's created once and shared across every call. Use None as the default and create the mutable object inside the function instead.
List vs. generator:a list comprehension builds the entire result in memory immediately; a generator expression (with parentheses instead of brackets) produces items one at a time and is far more memory-efficient for large or infinite sequences.
Common mistake — is vs. ==:== checks value equality; is checks object identity. Using is to compare strings or numbers can appear to work due to caching, then break unpredictably.
Common mistake — modifying a list while iterating:removing or adding items to a list during a for loop over that same list silently skips elements. Iterate over a copy (for x in list[:]) or build a new list instead.
