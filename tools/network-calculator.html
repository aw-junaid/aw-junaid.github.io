✦ How This Tool Works

What problem does VLSM actually solve?

Fixed-length subnetting (giving every department the same size block) wastes address space when host counts differ wildly — a 5-person branch office doesn't need the same /24 as a 200-person one. VLSM sizes each block to its actual requirement and packs them together, largest-first, so the whole plan fits in the smallest possible base network with no overlap.

Why does the base network matter for VLSM?

Every requirement is allocated as a sub-block of the base network you provide, in order, starting from its first address. If your requirements don't fit inside the base network's total address space, the tool reports how much space is missing rather than silently overflowing into the next network.

What does "over-inclusion" mean for a supernet?

The smallest CIDR block that covers a set of networks is bound by binary alignment — it can only start on an address divisible by its own block size. That often means the resulting supernet also covers extra address space you didn't list. The warning tells you how much extra space is included so you don't accidentally summarize away a route you needed to keep separate.

Why offer both /31 point-to-point and /32 host routes?

RFC 3021 allows a /31 to carry exactly two usable addresses with no network/broadcast reserved — the standard choice for router-to-router WAN links, since it doesn't waste a full /30 on a 2-host link. A /32 is for a single address, typically a loopback interface or an exact static route to one host.

What's a wildcard mask, and why isn't it just the subnet mask?

A subnet mask marks which bits define the network (1) vs. the host (0). A wildcard mask is the bitwise inverse — 0 means "this bit must match," 1 means "don't care" — because Cisco ACLs and OSPF network statements were built around matching, not addressing. For a standard subnet the wildcard is simply 255.255.255.255 minus the netmask.

Is anything sent to a server?

No. Every calculation — VLSM allocation, supernet search, wildcard generation, the reference table — runs entirely in your browser. Your inputs and settings only persist in this browser's local storage.
