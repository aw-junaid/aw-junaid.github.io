Two contracts, two invoice batches, two exported reports — which pages actually changed? Diff two PDFs page by page: text insertions and deletions inline, pages that were added, removed, or reordered, pixel-level visual differences for scanned/image pages, and metadata drift — all matched intelligently even when page counts don't line up.
Why a real diff beats "eyeballing it"

Contract redlines, regenerated reports, and re-exported invoices rarely diff 1:1 by page number — a single inserted page shifts everything after it. This tool aligns pages by content similarity first, so an inserted or deleted page doesn't cascade into false mismatches on every page that follows it.

✦ How This Tool Works

How are pages matched between the two files?

Each page's extracted text is compared against every page in the other file using a similarity score. The highest-scoring pairs above your match threshold are linked first, so an inserted page in the middle of the document doesn't shift every page after it out of alignment.

What's the difference between "Edited" and "Moved"?

An edited page matched to the same relative position but its text content changed. A moved page matched with high similarity — meaning it's essentially the same content — but appears at a different page number, which usually means the document was reordered.

When should I use Visual Diff instead of Text Diff?

Text diff only sees extractable text — it's blind to scanned pages, embedded images, charts, or logo changes. Visual diff renders both pages to canvas and highlights pixel regions that differ, which catches layout shifts and image changes text-only comparison would miss entirely.

Why does "Ignore numeric-only changes" carry a warning?

It's built for skipping noise like shifting page footers or auto-generated timestamps, but the same logic would hide a changed dollar amount, quantity, or date inside contract or invoice text. Leave it off for anything where a number itself is the thing you need to catch.

What does the similarity percentage mean?

It's a weighted score across matched-page text similarity, plus penalties for added, removed, and reordered pages — a single-word typo fix scores near 100%, while a document with several rewritten sections and a few extra pages will score much lower.

Is anything uploaded to a server?

No. Both PDFs are loaded, rendered, and diffed entirely in your browser — nothing is sent anywhere, which matters most for exactly the contracts and confidential documents this tool is built to compare. Reload the page and everything is cleared except your settings.
