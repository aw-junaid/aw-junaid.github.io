PDF OCR Tool

Scanned contracts, old textbooks, faxed forms, and photographed receipts all end up as PDFs you can't search, select, or copy from — just a flat picture of text. This tool reads the text back out with OCR, right in your browser, and gives you a searchable PDF, plain text, or word-level JSON with a confidence score for every single word.
The problem this solves

A scanned page is pixels, not characters — Ctrl+F finds nothing, screen readers skip it, and you can't paste a clause into an email. This tool rasterizes each page, runs multi-language text recognition on it, and lets you export a new PDF with an invisible, perfectly-aligned text layer on top of the original page image — so it looks the same but is now fully searchable and selectable.

✦ How This Tool Works

How does "searchable PDF" actually work?

Each page is rendered to an image at your chosen scale, OCR finds every word and its exact pixel position, and that position is mapped back into PDF point coordinates. The original page image is kept fully visible; an invisible text layer sits exactly on top of it, so Ctrl+F and text selection work without changing how the page looks.

Why does preprocessing matter so much?

OCR engines are built for flat black text on white background — a slightly tilted scan, low contrast, or background shading can turn a clean page into a wall of misreads. Deskewing, grayscale conversion, and binarization normalize the image before recognition even starts, which is usually a bigger accuracy lever than any engine setting.

What does the confidence score mean?

Tesseract returns a 0-100 confidence value per word based on how certain it is about the match. Low scores usually mean blurry source material, an unusual font, or the wrong language pack selected — the Confidence Map tab highlights exactly which words to manually double-check rather than trusting the whole page blindly.

Can it handle documents in more than one language?

Yes — select multiple language chips and Tesseract loads and checks against all of them together, which helps with bilingual contracts, forms, or captions. Each additional language increases the model data downloaded and the time recognition takes.

Why is Page Segmentation Mode adjustable?

OCR needs to know how the page is laid out before it can read it. "Single uniform block" suits a plain letter or book page; "sparse text" suits receipts, forms, or IDs with scattered short fields; the wrong mode can merge unrelated columns or miss isolated text entirely.

Is anything uploaded to a server?

No. Pages are rendered and recognized entirely in your browser using WebAssembly — nothing is sent anywhere, which matters most for exactly the sensitive scans (IDs, contracts, medical forms) this tool is built for. Reload the page and everything is cleared except your settings.
