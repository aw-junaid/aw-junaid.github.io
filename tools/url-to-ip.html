✦ How This Tool Works

How does resolution work from a browser?

Browsers can't send raw DNS packets, so this queries public DNS-over-HTTPS (DoH) JSON APIs \u2014 Cloudflare, Google, Quad9, or a custom endpoint you provide. The resolver performs the real recursive lookup, including following any CNAME chain, and returns the answer as JSON.

Why would resolvers disagree on a hostname's IP?

Content delivery networks and geo-load-balanced services intentionally return different IPs depending on where the resolver making the request is located, to route each visitor to a nearby edge node. A mismatch here is usually that by design \u2014 not a misconfiguration \u2014 though it's also exactly what you'd see during a slow DNS propagation window after a genuine change.

What's the SSRF check actually protecting against?

Server-Side Request Forgery happens when an app fetches a URL a user controls, and that URL's hostname resolves to an internal address \u2014 a cloud metadata endpoint, an internal admin panel, localhost. Because DNS answers aren't guaranteed to stay the same between the time you check and the time you fetch (DNS rebinding), this check is a starting point for manual review, not a substitute for enforcing IP allowlists at request time in your own infrastructure.

What does forward-confirmed reverse DNS actually verify?

A PTR record is set by whoever controls the IP's reverse zone, not by the domain owner, so it can claim to be anything. Forward-confirming it \u2014 resolving the claimed hostname's own A records and checking they include the original IP \u2014 shows that whoever controls the forward zone agrees with the PTR claim, which is the basis of checks used to validate mail servers and search-engine crawlers.

Why does CNAME chain length matter?

Modern stacks often chain several aliases \u2014 your domain to a CDN, the CDN to a load balancer, the load balancer to a regional endpoint \u2014 before reaching an A record. Seeing the full chain helps you tell whether you're looking at your own DNS or a third party's, and is often the fastest way to confirm a CDN or SaaS integration is actually wired up.

Is anything sent to a server?

Only to the public resolvers you select, to perform the DNS queries, and optionally to ipapi.co if you enable the geolocation toggle. Nothing is sent to any server we operate, and results are never stored \u2014 they exist only in your browser tab.
