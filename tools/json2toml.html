✦ How This Tool Works

Why do some nested objects become [tables] and others stay inline?

TOML supports both. A nested JSON object becomes its own [table] section by default. With "Inline shallow objects" on, a small flat object (at or under the key-count threshold, with no objects of its own) is instead written as an inline table like owner = { name = "x", id = 1 } on a single line — handy for compact leaf records.

How are arrays of objects converted?

By default each object in an array becomes its own [[array-of-tables]] section, which is how tools like Cargo.toml represent repeated records (e.g. [[dependencies]]). Turn on "Render object arrays as inline arrays" to instead get a single line of inline tables: items = [ {...}, {...} ].

Why are some keys wrapped in quotes?

TOML bare keys may only contain letters, digits, underscores, and hyphens. Any JSON key with spaces, dots, or other punctuation — like "weird key" or "dotted.key" — is automatically quoted so it's read as one literal key rather than a nested path.

What happens to JSON null values?

TOML has no null type, so you choose the strategy: omit the key entirely (closest to "field not set"), write it as an empty string, or keep it visible but commented out so you can see what was dropped and why.

How does date detection work?

With "Detect ISO 8601 date/time strings" on, values matching a full date, full time, or offset/local date-time pattern (e.g. 2026-08-23T09:15:00Z) are emitted unquoted as native TOML date-time values instead of plain strings — matching how config files typically store timestamps.

What's the difference between literal and basic strings?

Basic strings use double quotes and support escape sequences. Literal strings use single quotes with no escaping at all, which keeps things like Windows paths or regex patterns readable. "Prefer literal strings" uses them automatically wherever a value contains no single quote or control character.

What is the Table Map for?

Before trusting a large converted config, it helps to see the shape at a glance. The Table Map lists every [table] and [[array-of-tables]] header the conversion produced, in order, so you can quickly confirm the structure matches what you expected.

Can I convert multiple files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .toml files into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
