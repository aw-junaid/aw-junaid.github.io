✦ How This Tool Works

Why keep /*! ... */ comments even with "remove comments" on?

Many libraries rely on a license or attribution banner surviving minification — bundlers and other minifiers (like Terser and cssnano) honor the "bang comment" convention for exactly this reason. Turn "Preserve /*! license */ comments" off if you want every single comment gone.

Is it safe to convert rgb()/rgba() to hex?

Only when the color is fully opaque — no alpha channel, or an alpha of exactly 1. A translucent rgba() color can't be represented as a plain 6-digit hex without changing what renders, so those are left untouched.

Why is "Sort declarations alphabetically" off by default?

CSS lets you override a shorthand with a more specific longhand as long as it comes later, e.g. background: red; background-color: blue;. Alphabetical sorting can silently reverse pairs like this. De-duping same-named properties is always safe; reordering different ones occasionally isn't.

What counts as a "duplicate selector" merge?

Only rule blocks that are directly adjacent with an identical selector list are combined — e.g. two back-to-back .btn { ... } .btn { ... } blocks. Selectors separated by other rules are left alone, since merging them could change which rule wins for properties with equal specificity.

Does this touch @media, @supports, @keyframes, and @font-face?

Yes. Nested at-rules like @media and @supports are minified recursively, empty ones are dropped once their contents optimize away, and declaration-only at-rules like @font-face, @page, and @viewport get the same declaration-level optimizations as a normal rule.

What is the Rule Tree for?

Before trusting a large minified stylesheet, it helps to see its shape at a glance. The Rule Tree lists every selector and at-rule from your input in order, with a declaration count, so you can quickly confirm nothing important got dropped.

What does the Optimization Report show?

A before/after byte count and percentage reduction, plus a breakdown of what the pass actually did — comments removed, empty rules dropped, duplicate selectors merged, and duplicate declarations de-duped — so the savings aren't a black box.

Can I convert multiple stylesheets at once?

Yes — upload or drag in several .css files and each becomes a tab above the editor. "Download All (.zip)" minifies every loaded file with your current settings and bundles the resulting .min.css files into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
