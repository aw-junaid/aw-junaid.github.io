✦ How This Tool Works

How are [sections] turned into JSON?

Each [section] becomes a top-level key holding an object of its key/value pairs. With "Nest sections by separator" on, a name like [database.primary] is split on the dot and turned into database → primary as nested objects, matching how many real configs group related settings.

What happens to keys that appear before any section header?

Some INI files start with loose key = value lines before the first [section]. With "Keep keys found before any section" on, those are collected under the global-section key name you set above instead of being silently dropped.

How are duplicate keys and sections handled?

Real-world INI files often repeat a key or reopen the same section further down the file. Choose "Last wins" to overwrite, "Collect as array" to gather every value, or "Error" to fail loudly under Strict Mode so you catch accidental duplicates before they cause bugs.

Does it support comments, quoting, and line continuation?

Yes — full-line and inline comments starting with ; or # are stripped, matching quotes around a value are removed, escape sequences like \n and \" are unescaped inside quoted values, and a trailing backslash joins a value onto the next line.

How are lists/arrays represented in INI?

Two common conventions are supported: comma-separated values on one line (tags = a, b, c) via "Split comma-separated values", and repeated PHP-style key[] = value lines via "Support PHP-style key[] arrays", which collect every match into a single JSON array.

What does the Tree View and Inferred Schema show?

Tree View lays out the converted JSON as an indented outline of keys, types, and values so you can scan deeply nested results at a glance. Inferred Schema generates a best-effort JSON Schema (types, object properties, array item shapes) from your data — a useful starting point, not a substitute for a hand-written schema.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
