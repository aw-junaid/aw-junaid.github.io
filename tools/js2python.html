✦ How This Tool Works

Is this actually parsing my code, or just find-and-replace?

It parses. Your JavaScript is run through Acorn, a real ECMAScript parser, which builds an AST (abstract syntax tree) in the browser. The converter then walks that tree node by node and emits Python — the same general approach a real transpiler uses, just aimed at readability over 100% semantic equivalence.

What happens to syntax it can't convert?

Nothing is silently dropped. Unsupported constructs (things like labeled loops, comma expressions, or exotic destructuring) are kept as a commented-out copy of your original source at the exact spot they occurred, and every one is also listed in the Conversion Notes tab with its line number.

How are switch statements handled?

Each case becomes an elif branch comparing against the discriminant. Consecutive empty cases that fall through to a shared block are grouped into a single discriminant in (a, b, c) check, and default becomes the trailing else.

How are classes converted?

this becomes self, constructor becomes __init__, class fields are folded into the constructor, and static methods get a @staticmethod decorator. get/set accessors become @property and @x.setter when that setting is on.

What does the AST View and Conversion Notes show?

AST View is an indented outline of the parsed JavaScript — every node type and key value, useful for understanding exactly what the parser saw. Conversion Notes lists anything the generator couldn't confidently translate, so you know exactly what to review by hand before running the output.

Can I convert multiple files at once?

Yes — upload or drag in several .js files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .py files into one archive.

What does Strict Mode change?

With Strict Mode on, a JS syntax error stops conversion immediately and shows the exact line and column Acorn choked on. It doesn't affect how already-valid-but-unusual JavaScript is handled — that's what Conversion Notes and inline warnings are for.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser, and both parsing and conversion happen entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
