✦ How This Tool Works

What problem does this actually solve?

IPv6's 128-bit addresses are unwieldy by hand: compressing and expanding notation, carving a /48 allocation into /64 links, or checking whether a customer's block overlaps another all require exact binary math. This tool does that math with full 128-bit precision and shows every derived value at once.

How does subnet splitting decide the new prefix?

Choose "new prefix length" to fix the child size directly, or "number of subnets" to have the tool round up to the nearest power of two automatically. Both modes cap the number of subnets actually listed, since a large prefix difference can generate more rows than a browser tab should render.

How is EUI-64 generated from a MAC address?

The 48-bit MAC is split down the middle, the fixed bytes FF:FE are inserted in the gap, and the universal/local bit in the first byte is flipped. The resulting 64-bit interface ID is then combined with the network portion of the address to form a full autoconfigured address.

What is the solicited-node multicast address for?

Every unicast or anycast address maps to a corresponding ff02::1:ff00:0/104 multicast group, built from its low-order 24 bits. Neighbor Discovery uses this group instead of broadcast, so this tool derives it automatically for the address you enter.

What do "contains" and "overlap" check?

"Does A contain B?" tests whether every address in subnet B falls inside subnet A's range — useful for confirming a customer allocation sits inside your issued block. "Overlap" instead checks whether A and B share any addresses at all, which is what you want when auditing for conflicting assignments.

Is anything uploaded to a server?

No. Every calculation — parsing, subnetting, EUI-64, reverse DNS, comparisons — runs locally in your browser with native 128-bit integer math. Nothing you type or upload is sent anywhere, and your draft and settings only persist in this browser's local storage.
