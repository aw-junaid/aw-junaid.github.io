✦ How This Tool Works

Where do the ge/le/min_length/max_length numbers come from?

They're read straight from your pasted JSON — the smallest and largest number (or string length) seen for that field across every sibling sample. They're a starting point derived from one snapshot, not a guarantee about production traffic, so treat them as something to review and widen, not ship blindly.

How does it decide a field is sensitive?

By key name only — things like password, token, secret, api_key, or ssn get wrapped in SecretStr so the value doesn't leak into logs, tracebacks, or repr() output. It never inspects or stores the actual sensitive value in the generated comments — those are masked.

Why Decimal instead of float for money fields?

Binary floating point can't represent most decimal fractions exactly (0.1 + 0.2 isn't quite 0.3), which is a real source of off-by-a-cent bugs in billing code. Fields whose key name looks monetary (price, amount, total, cost, balance) are typed as Decimal instead, which is what most payment APIs expect.

What does the alias generator do versus per-field aliasing?

Per-field aliasing adds an explicit Field(alias="camelKey") to each renamed attribute. The alias generator instead sets model_config = ConfigDict(alias_generator=to_camel, populate_by_name=True) once, so every snake_case field automatically accepts its camelCase JSON key without listing each one — better when the whole API is consistently camelCased.

What's the difference between the BaseModel and BaseSettings root styles?

BaseModel validates a JSON payload (a request/response body). BaseSettings (from pydantic-settings) instead reads values from environment variables or a .env file at startup — useful when the pasted JSON represents your app's configuration shape rather than API traffic.

Does it handle nested objects and arrays of objects?

Yes — nested objects become their own BaseModel classes (deduplicated when structurally identical), and arrays of objects become List[ThatModel]. Inconsistent element shapes within one array are flagged in the Conversion Notes tab for manual review.

Can I convert multiple JSON files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .py modules into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere, which matters given this tool often sees real payloads with sensitive-looking field names. Your draft and settings only persist in this browser's local storage.
