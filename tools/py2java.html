✦ How This Tool Works

How does type inference work without a Python type checker?

The converter reads literals, arithmetic, and any type hints you've written (x: int, -> List[str]) to guess a Java type per variable. When it truly can't tell, it either falls back to var (if that setting is on and the target JDK supports it) or emits the default integer/float/String type you've configured, and logs a note so you can double-check it.

Why does everything end up wrapped in a class?

Java has no free-standing top-level statements — every method and field lives inside a class. Top-level Python code is collected into a main(String[] args) method on the public class you name above; functions become static methods on the same class unless you split classes yourself.

Why does it flag things instead of just converting them?

Python and Java solve some real-world problems differently by design — duck typing, generators, multiple inheritance, **kwargs, and dynamic re-typing of a variable don't have a clean 1:1 Java equivalent. Rather than silently emitting something that compiles but behaves differently, the tool flags these constructs in the Conversion Notes tab for manual review.

How are Python containers mapped to the Collections Framework?

Each container type has its own dropdown: lists can become ArrayList or LinkedList; dicts become HashMap, LinkedHashMap, or sorted TreeMap; sets work the same way. Pick the ordered/sorted variants when you need Python's dict-insertion-order or sorted-key guarantees preserved. Since Java generics can't hold primitives, list/map element types are auto-boxed (int → Integer, etc.).

What's the difference between the data class styles?

Plain class generates private fields with getters/setters — closest to a typical Python class with properties. Record (JDK 16+) generates an immutable record, ideal for simple data-holder classes with no behavior. Public-fields skips accessors entirely for terse, competitive-programming-style code.

Does it generate the right import list automatically?

Yes, when "Auto-detect required imports" is on — it scans the generated Java for usages like ArrayList, HashMap, or Optional and only imports what's actually needed. Turn it off to manage imports yourself.

Can I convert multiple files at once?

Yes — upload or drag in several .py files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .java files into one archive.

What do the built-in presets change?

Modern Java 17/21 favors var, records, and streams. Enterprise/Spring-style keeps explicit types and full getters/setters. Competitive Programming adds fast I/O and terser output. Android/Mobile avoids streams and newer syntax for wider compatibility. Teaching/Verbose keeps every comment and spells out types instead of using var.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
