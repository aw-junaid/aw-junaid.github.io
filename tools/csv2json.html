✦ How This Tool Works

Does this handle commas inside quoted fields?

Yes — this isn't a naive split-on-delimiter converter. It's a real character-by-character CSV parser, so a field like "Los Angeles, CA" or a quoted value containing a literal newline stays intact as one field instead of breaking the row apart.

How does delimiter auto-detection work?

On "Auto-detect", the tool counts commas, semicolons, tabs, and pipes in the first non-comment line and picks whichever appears most consistently. If your file uses something unusual, set a custom delimiter directly instead of relying on auto-detect.

What does dot-notation nesting do?

A header such as address.city or address.zip builds a nested address object on each record instead of a flat key with a literal dot in its name — handy for CSV exports that flatten nested data for spreadsheets.

What's the difference between the four output shapes?

Array gives one object per row (most common). Columnar gives one array per column — useful for charting libraries. Keyed turns rows into a lookup map keyed by a column you choose, like an id. JSON Lines writes one compact object per line for streaming/log-style ingestion.

What does Strict Mode change?

With Strict Mode on, a row with more or fewer fields than the header stops conversion with the exact row number. With it off, short rows are padded with null and long rows have extra fields dropped, with a warning shown above the input.

Can I convert multiple files at once?

Yes — upload or drag in several .csv/.tsv files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the results into one archive.

What happens to the null-token list?

Any field whose trimmed value exactly matches an entry in the null-token list (e.g. NULL, N/A, -) becomes JSON null, separately from how a genuinely empty field is handled.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
