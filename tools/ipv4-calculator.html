✦ How This Tool Works

What's the difference between the three input modes?

CIDR prefix (like /24) is the modern shorthand for the mask. Dotted subnet mask (255.255.255.0) is the same value written the older way, still common in Windows and some router configs. Wildcard mask (0.0.0.255) is the inverted mask that Cisco ACLs and OSPF network statements expect — the calculator converts between all three automatically.

Why exclude the network and broadcast address?

On any subnet /1 through /30, the first address identifies the network itself and the last is reserved for broadcast — neither can be assigned to a host. Toggle it off if you specifically want the raw address count instead of the usable host count. /31 and /32 are handled separately since RFC 3021 and host routes don't follow the same rule.

How does VLSM subnet splitting decide where each block starts?

Variable Length Subnet Masking packs subnets of different sizes into one block without overlap. The calculator sorts nothing for you — it walks your list top to bottom, rounds each requirement up to the smallest subnet that fits it, aligns that subnet's start address to its own boundary, and places it right after the previous one. Feeding requirements largest-to-smallest wastes the least address space.

What does the Supernet / CIDR Aggregation tool do?

Given two or more separate network blocks, it finds the smallest single CIDR that contains all of them — useful for collapsing a long list of routes into one summary route on a router, or checking whether a set of allocated blocks could be represented more compactly.

How does Reverse Planning work?

Tell it how many hosts a subnet needs to hold, and it works backward to the smallest prefix that provides enough usable addresses. Tell it how many subnets you need to carve out of the current network, and it works out how many extra bits of prefix that requires and what the new prefix would be.

Is anything uploaded to a server?

No. Every calculation — parsing, subnetting, aggregation, batch conversion — runs entirely in your browser with plain JavaScript. Nothing you type is sent anywhere. Your last input and settings only persist in this browser's local storage.
