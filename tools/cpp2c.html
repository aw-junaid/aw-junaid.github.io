✦ How This Tool Works

How are classes turned into plain C?

Each class becomes a typedef struct holding only the data members. Every method becomes a free function taking an explicit pointer to that struct as its first argument, named per your chosen convention (e.g. Greeter_greet(Greeter* self)). Constructors and destructors become ordinary _create/_destroy functions you must call yourself.

How is virtual dispatch emulated?

When enabled, the tool embeds a small struct of function pointers (a manual vtable) as the first member of the class struct, and generates an _init routine that wires each pointer to the concrete implementation — the same technique real C runtimes and libraries like GObject use for polymorphism.

Why does it flag templates and multiple inheritance?

Neither has a mechanical, always-correct C equivalent. Templates would need either void*-based generics, X-macro duplication, or one hand-written function per instantiation — a design decision, not a translation. Multiple inheritance needs manual vtable offset math the tool won't guess at, so both are flagged for manual review instead of silently emitting something that compiles but misbehaves.

What happens to std::vector, std::string, and std::map?

Vectors can become a generated growable-array struct with push/free helpers, or a fixed-size C array if the length is known. Strings map to char* with buffer-management notes. Maps and sets have no built-in C equivalent at all, so by default they're flagged for a hand-written hash table or a small linear array, depending on your dropdown choice.

How does exception handling translate?

try/catch/throw is rewritten into your chosen error-propagation style — typically an integer return code checked immediately after each call. This is a real semantic change: stack unwinding and automatic cleanup don't exist in C, so any RAII destructor that used to run on an exception path is flagged so you can add an explicit cleanup call.

Can I convert multiple files at once?

Yes — upload or drag in several .cpp/.hpp files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .c files into one archive.

What do the built-in presets change?

Portable C89 hoists declarations to the top of each block and avoids stdbool.h. Modern C11/C17 keeps bool and newer conveniences. Embedded/Constrained prefers stack allocation and flags anything that needs the heap. Readable/Teaching keeps every comment and spells out types instead of terse inference.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
