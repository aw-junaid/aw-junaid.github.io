✦ How This Tool Works

Does this fully re-parse and rewrite my code like Prettier?

No — it's a lighter-weight tokenizer-based formatter that runs entirely in your browser. It re-indents based on bracket nesting, fixes spacing, quotes, commas and semicolons, but it deliberately does not reflow or rewrap your existing line breaks. That keeps it fast, predictable, and safe to run on real code without a full JavaScript engine.

Why didn't it add a semicolon on every line?

Automatic Semicolon Insertion in JavaScript has real edge cases — a line starting with (, [, a backtick, or an arithmetic operator can silently merge with the line above it. This tool only inserts or removes semicolons on lines it can confirm are safe, and lists anywhere it held back on the Warnings tab so you can check it by hand.

Why is the closing brace of an arrow function assigned to a variable missing a semicolon?

This is a known, intentional limitation. Telling a block body (if, for, a function) apart from an object literal or an arrow-function body that's itself part of a larger statement needing a semicolon requires more context than a line-based formatter safely tracks. The formatter always errs on the side of not risking a syntax change — review these spots manually.

How does trailing comma handling work?

The formatter adds or removes a trailing comma only on the last item of an array, object, or (with "All") function argument list that's already spread across multiple lines — never inside a for (;;) header, a grouping (...), or a class body. "None" also strips a stray trailing comma from a single-line list.

What does "Arrow function parentheses" change?

x => x * 2 and (x) => x * 2 are both valid for a single simple parameter. "Always" wraps a bare parameter in parentheses; "Avoid" strips them back off when the sole parameter is a simple identifier (no default, destructuring, or rest syntax involved).

What is the Outline tab for?

Before trusting a large formatted file, it helps to see its shape at a glance. The Outline lists top-level function, class, const/let/var declarations and named exports in the order they appear, so you can quickly sanity-check nothing structural changed.

Does it understand JSX or TypeScript?

The tokenizer targets plain JavaScript (ES2020+ syntax including optional chaining, nullish coalescing, private class fields and template literals). JSX tags and TypeScript-only syntax like type annotations aren't specifically recognized and may format unpredictably — stick to plain .js input for reliable results.

Can I convert multiple files at once?

Yes — upload or drag in several .js files and each becomes a tab above the editor. "Download All (.zip)" formats every loaded file with your current settings and bundles the results into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
