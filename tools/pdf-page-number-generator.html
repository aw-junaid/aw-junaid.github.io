PDF Page Number Generator

Reports, theses, contracts, and manuals all need page numbers that actually match how they're printed and bound — a cover page with no number, roman numerals on the preface, "Page X of Y" on the body, mirrored margins for double-sided binding. Set it once, preview it live, and stamp every page correctly in one pass.
Built for the messy real-world case, not just "1, 2, 3…"

Most page-number tools only do a single number in a single corner. Real documents need a cover page skipped, front matter numbered in roman numerals restarting at i, the main body restarting at 1, specific ranges excluded (blank pages, dividers), and — for anything bound and printed double-sided — the number mirrored to the outer edge on alternating pages. All of that is configurable here, previewed before you commit, and applied consistently across a whole batch of files.

✦ How This Tool Works

How do I skip the cover page?

Set "Skip first N pages" to 1 (or however many front pages should stay blank), and turn on "Restart count at first numbered page" so numbering starts clean at your Start value from the first page that actually gets stamped, rather than continuing from a hidden count.

Can I number front matter differently from the body?

Run the tool twice on the same source: first with a roman-numeral format restricted to the front-matter range (e.g. "2-6"), then load that output again and apply an arabic "Page {page} of {total}" format restricted to the remaining range starting at 1.

What does "Mirror odd/even pages" actually do?

For anything printed double-sided and bound, the page number should sit on the outer edge of the sheet, not the same corner on every page. This flips a left/right anchor to the opposite side on even-numbered pages automatically.

How does the page range syntax work?

Comma-separated, with dashes for spans: "1-5,8,10-end" numbers pages 1 through 5, page 8, and 10 through the last page. Anything in the "Exclude" field is removed from that set afterward, even if it overlaps.

Does the total in "Page X of Y" count every page or just numbered ones?

Your choice — "Auto" counts only the pages actually being numbered (so a skipped cover doesn't inflate the total), while "Total pages in document" always reflects the PDF's real page count regardless of what's excluded.

Is anything uploaded to a server?

No. Every PDF you load is processed locally in your browser using pdf-lib — nothing is sent anywhere. Reload the page and everything clears except your saved settings.
