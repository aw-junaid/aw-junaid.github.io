✦ How This Tool Works

Why does the output include an XML declaration?

Most consumers (parsers, config loaders, feed readers) expect a leading <?xml version="1.0" encoding="UTF-8"?> line. You can turn it off, or change the version, encoding, and standalone attribute under "Declaration & Doctype" if your target system needs something specific.

What happens to empty elements?

By default an element with no children, like <br></br>, is collapsed to the shorter self-closing form <br/>. Turn off "Self-close empty elements" if a downstream parser specifically expects the long form.

Why are some elements' whitespace left untouched?

Elements like <pre> or <script> often carry meaningful whitespace. List their tag names under "Preserve whitespace in listed elements" and their text content is kept exactly as written, even while everything else gets re-indented.

How is CDATA handled?

By default <![CDATA[...]]> sections are kept byte-for-byte, which is the safe choice for embedded HTML, scripts, or characters like & and < that would otherwise need escaping. Turn on "Convert CDATA to escaped text" to normalize it into regular escaped text instead.

Why would I sort or wrap attributes?

Sorting attributes alphabetically makes diffs between versions of a config file much smaller and easier to review. Wrapping puts each attribute on its own line once a tag gets long, which is common practice for elements with many attributes (like Android layout XML or Maven POMs).

What does "Strict mode" actually check?

The tool parses your XML with the browser's built-in XML parser. With strict mode on, any well-formedness problem — an unclosed tag, a bad entity, mismatched quotes — surfaces the parser's own error message instead of the tool silently guessing at a fix.

What is the Element Map for?

Before trusting a large formatted document, it helps to see the shape at a glance. The Element Map lists every element in document order with its depth and attribute names, so you can quickly confirm the structure matches what you expected — similar to skimming a table of contents.

Can I convert multiple files at once?

Yes — upload or drag in several .xml files and each becomes a tab above the editor. "Download All (.zip)" formats every loaded file with your current settings and bundles the results into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
