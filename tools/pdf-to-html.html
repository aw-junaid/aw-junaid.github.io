✦ How This Tool Works

Which conversion mode should I use?

Reflowable is the everyday choice for a text-heavy document you want to read, edit, or publish as an article — it rebuilds paragraphs, headings and tables. Positioned reproduces the original layout exactly, which matters for forms and dense mixed layouts. Rasterized turns each page into an image, which is the safest option for scans, heavy graphics, or anything that would break if reflowed.

How does heading and table detection work?

Headings are text lines that stand alone as their own paragraph and are noticeably larger than the document's typical font size — the sensitivity setting controls how much larger. Tables are detected when several consecutive lines share the same aligned column gaps; those lines become a real <table> instead of a paragraph.

What does "strip repeated headers/footers" remove?

It looks at the first and last line of every page, normalizes out page numbers, and drops any line that repeats near the same position on most pages — the running title or footer that would otherwise appear dozens of times in a reflowed article.

Will the output still be searchable if I rasterize it?

Yes, if you keep "Add invisible searchable text overlay" on — it places the PDF's real text transparently over each page image, the same layered approach browsers use to make scanned, OCR'd PDFs selectable and searchable.

Why does Positioned mode skip image extraction?

Placing an extracted image at its exact original position requires re-deriving the page's full graphics transform, which is a much harder problem than positioning text. Rasterized mode sidesteps this entirely by rendering the finished page — use it whenever a page's images and graphics matter as much as its text.

Is anything uploaded to a server?

No. The file you add is read and converted locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
