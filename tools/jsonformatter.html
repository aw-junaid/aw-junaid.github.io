✦ How This Tool Works

Why does this accept JSON that isn't technically valid?

Real-world "JSON" is often copied from a JS source file, a config with comments, or hand-edited text — which means trailing commas, // notes, single quotes, or bare keys like name:. The lenient parser accepts all of that, then rewrites it as spec-clean JSON. Turn on "Strict mode" if you specifically need to validate against RFC 8259.

What does duplicate key detection catch?

In JSON, if a key appears twice in the same object, most parsers silently keep only the last value — the first is discarded with no warning. That's a common source of "why did my config not apply" bugs. This tool lists every duplicate with its line and column so you can decide which value should actually win.

Why would I "preserve large integers exactly"?

JavaScript numbers lose precision above 253, which matters for things like 64-bit database IDs or Twitter/Discord snowflake IDs. With this on, oversized integers are carried through as-is, digit for digit, instead of being silently rounded.

How do I get errors instead of a repaired file?

Enable "Strict mode." Any comment, trailing comma, single-quoted string, or unquoted key will then be reported as a syntax error with an exact line and column, instead of being auto-repaired — useful when you need to confirm a file is genuinely valid before it goes to a strict downstream parser.

What does "compact primitive arrays" change?

By default, pretty-printing puts one array item per line. For short arrays containing only numbers, strings, or booleans (e.g. tags: ["prod", "edge"]), this keeps them on a single line instead, up to the width you set — object and nested arrays are always expanded normally.

Is sorting keys safe to use on API payloads?

JSON objects are unordered by spec, so re-ordering keys doesn't change meaning to any conforming parser. Sorting is mainly useful for making two versions of a config diff cleanly, or for producing a canonical form for hashing/comparison — not something you'd typically do to a live API response.

Can I convert multiple files at once?

Yes — upload or drag in several .json/.jsonc files and each becomes a tab above the editor. "Download All (.zip)" formats every loaded file with your current settings and bundles the results into one archive. Nothing is uploaded to a server; everything runs locally in your browser.

Where do error line and column numbers come from?

The parser tracks position character-by-character as it reads your input, so when it hits something unexpected — a missing comma, an unterminated string, a stray bracket — it reports the exact line and column of the offending character, the same way a strict JSON linter would.
