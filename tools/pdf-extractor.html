✦ How This Tool Works

How do I write a page range?

Use comma-separated numbers and dashes, like 1-3,7,10-12. Each comma-separated group can become its own output file if you set "Output as" to per-comma-group — useful for pulling several unrelated sections from one source in a single pass.

What's the difference between Burst All and Every N Pages?

Burst All splits every single page into its own file — ideal for feeding pages to a scanner queue or an image pipeline. Every N Pages groups pages into fixed-size chunks (e.g. every 5 pages), which is handy for splitting a long scanned batch back into original multi-page documents.

What does "Invert selection" actually delete?

Turning on invert flips the logic of whichever mode is active: instead of keeping the matched pages, the output keeps everything else. Combine it with Page Range to delete a specific range (e.g. remove pages 4-6 from a 20-page report) without needing a separate "delete pages" tool.

Why would I use Manual Pick instead of typing a range?

Manual Pick renders a thumbnail of every page so you can click exactly the ones you want — useful when you don't already know the page numbers, like pulling every page with a diagram out of a long scanned book.

Why would I strip metadata?

Extracted pages otherwise inherit the source file's author, producer, and timestamps. Enabling "Strip source metadata" clears that out before applying your own Title/Author/Subject fields — useful when re-purposing pages pulled from someone else's document.

Is anything uploaded to a server?

No. The PDF you choose is read and processed locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
