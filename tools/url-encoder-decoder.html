✦ How This Tool Works

Which encoding standard should I use?

Use Component for a single value going into a query string or path segment (mirrors JavaScript's encodeURIComponent). Use Full URI when the input is already a complete URL and you only want to escape unsafe characters while keeping : / ? # & = intact. Use Form for classic HTML form submissions (spaces become +). Strict RFC 3986 additionally escapes ! ' ( ) *, which some strict validators require. Legacy escape() replicates the deprecated JavaScript escape() function some older systems still expect.

Why do spaces sometimes turn into "+" and sometimes "%20"?

Both are valid, but they mean different things in different contexts. application/x-www-form-urlencoded bodies (classic HTML forms) use + for spaces, while the path and query of a URL per RFC 3986 use %20. Pick the Space Handling option that matches where the encoded string will actually be used.

What does "Never encode these characters" do?

Some APIs expect specific characters to stay literal even under strict encoding — for example keeping : and / readable in a URL shown to a user. List any characters here and, if they'd normally be escaped, the tool leaves them as-is in the output instead of writing their %XX form.

What's the difference between Strict decode and the default?

By default, decoding is lenient: a stray % that isn't followed by two valid hex digits (or a broken UTF-8 sequence) is left alone instead of crashing the whole conversion — handy for messy real-world logs. Turn on Strict decode to instead surface exactly where a percent-encoded string is malformed, which is useful when validating input.

What do the URL Components and Query Params tabs show?

URL Components parses a full URL into its protocol, credentials, host, port, path, query string and fragment. Query Params breaks the query string into an editable key/value table — decoded values are shown, and editing a row rebuilds the query string (and the Result tab) live, so it also works as a query-string builder.

What is the Byte Map tab for?

It shows, character by character, exactly which UTF-8 bytes (and therefore which %XX groups) each character encodes to. This is the fastest way to understand why non-ASCII text like emoji, accented letters, or CJK characters expand into multiple percent-encoded groups instead of one.

Can I convert a whole list at once?

Yes — set Batch Processing to "Line-by-line" to encode/decode every line of the input independently (each line's result stays on its own line, and errors on one line don't stop the rest), or "Each line as key=value pair" to treat every line as a query parameter and get back both a rebuilt query string and a per-line results table.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
