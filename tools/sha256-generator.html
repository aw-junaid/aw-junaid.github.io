✦ How This Tool Works

What problem does this actually solve?

Checksums show up everywhere: verifying a downloaded installer wasn't tampered with, generating an SRI attribute for a CDN script, signing a webhook payload, or comparing two files without opening either. This tool covers those cases from one input box, computed locally, without needing OpenSSL or a script.

Why offer SHA-1 and SHA-2 variants alongside SHA-256?

Published checksums aren't always SHA-256 — older software distributions still publish SHA-1, and some security-sensitive contexts use SHA-384 or SHA-512. Being able to match whatever length the vendor published, rather than only supporting one algorithm, is what makes the verification actually useful.

What is HMAC and when would I need it?

A plain hash proves data wasn't altered; HMAC additionally proves it was signed by someone holding a shared secret. Webhook providers (Stripe, GitHub, Shopify, and others) sign their payloads this way — your server recomputes the HMAC with the shared secret and compares it to the signature header to confirm the request is genuine.

Can I use the "Iterations" setting to hash passwords safely?

No. Repeating SHA-256 many times is not the same as a real password-hashing function — it lacks the memory-hardness and tunable work factor that make bcrypt, scrypt, Argon2, or PBKDF2 resistant to GPU and ASIC cracking. The iteration setting here is for demonstrating constructions like Bitcoin's double-SHA256, not for storing credentials.

What is Subresource Integrity (SRI) and how do I use it?

SRI lets a browser verify that a script or stylesheet loaded from a CDN hasn't been altered, by comparing it against a hash you provide. Hash the exact file you're linking to, then drop the generated sha256-... value into the tag: <script src="..." integrity="sha256-..." crossorigin="anonymous"></script>.

Is my file or text ever uploaded anywhere?

No. Every computation on this page — text hashing, file hashing, HMAC, verification — runs through your browser's built-in Web Crypto API. Nothing here makes a network request; unlike some of the other tools on this site, there's no third-party API call involved at all.
