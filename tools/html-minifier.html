✦ How This Tool Works

Is this a full HTML parser?

No. This minifier is regex-based, not a full DOM/tree parser like html-minifier-terser. It's tuned to be safe on typical hand-written markup, but it won't handle every malformed-HTML edge case perfectly. Always diff-check output on critical production pages.

What does "Aggressive" whitespace mode do that "Conservative" doesn't?

Aggressive removes all whitespace sitting directly between two tags (e.g. between </li> and <li>), which can visually change inline-element spacing in rare layouts. Conservative only collapses whitespace runs down to a single space, which is safer around inline elements like <span> and <a>.

Why does <pre> and <textarea> content stay untouched?

Whitespace inside those elements is meaningful to the browser, so their content — and the content of any tags you list under "Preserve content of these tags" — is protected before any collapsing, comment-stripping, or attribute processing runs, then restored byte-for-byte at the end.

How safe is the <script> minification?

It only strips // and block comments while tracking string, template-literal, and regex boundaries so it never touches code inside quotes or backticks. It does not rename variables, remove whitespace, or restructure code, so behavior is preserved — for maximum JS compression, run a real minifier like Terser separately.

What is the gzip estimate based on?

When your browser supports the CompressionStream API, the tool actually gzips the minified output in-memory and reports the real compressed byte size — the same algorithm most web servers use for gzip transfer-encoding — rather than a rough approximation.

Which attributes get removed as "redundant"?

Currently type="text/javascript" and type="application/javascript" on <script>, type="text/css" on <style>/<link>, and method="get" on <form> — all defaults that browsers already assume, so writing them out costs bytes for nothing.

Can I convert multiple files at once?

Yes — upload or drag in several .html files and each becomes a tab above the editor. "Download All (.zip)" minifies every loaded file with your current settings and bundles the results into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and minification happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
