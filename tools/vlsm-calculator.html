✦ How This Tool Works

What problem does VLSM actually solve?

Handing every department the same fixed-size subnet wastes huge amounts of address space — a 5-host WAN link doesn't need the same block as a 200-host floor. VLSM lets each requirement get a subnet sized to fit, carved out of one shared base network, so nothing is over-allocated and nothing overlaps.

Why does it sort largest-first by default?

Because subnets must start on an address boundary matching their own size, packing the biggest blocks in first and the smallest last leaves the smallest possible amount of unusable padding between allocations. Any other order still produces valid, non-overlapping subnets — it just tends to waste more space to alignment gaps, which the Gaps & Efficiency tab will show you.

Usable hosts vs. total addresses — which should I pick?

Usable hosts (the default) excludes the network and broadcast address, matching how you'd actually count assignable devices. Total addresses is useful when you're sizing a block for something like a NAT pool or DHCP scope where you want to reserve the full range rather than just host-assignable IPs.

What's an "alignment padding gap"?

Every subnet's network address must be a multiple of its own block size. If the next requirement is smaller than the space remaining after the previous allocation, some addresses between them can't be used by either block and sit idle. The calculator reports these gaps explicitly instead of silently swallowing the address space.

What does "Reserve spare pool at end" do?

It sets aside a percentage of the base network's total capacity at the very end, after all requirements are allocated, so it's never touched by the allocator — a common real-world practice for future departments or unplanned growth without having to renumber existing subnets later.

Is anything sent to a server?

No, with one exception: the "Detect My Public IP" button is opt-in and calls a third-party API (ipify.org) to look up your public IP. Everything else — parsing, sorting, allocation, padding detection, CSV/JSON export — runs entirely in your browser. Your draft and settings only persist in this browser's local storage.

Can I force an exact subnet size instead of a host count?

Yes — write /prefix as the value instead of a number, e.g. WAN Link,/30. That requirement is allocated at exactly that prefix regardless of the host-count settings, which is common for point-to-point links sized by convention rather than by host count.
