✦ How This Tool Works

How are headings detected?

In Auto mode, the tool samples font sizes across the document to find the body text size, then flags any line noticeably larger as H1/H2/H3. Manual mode lets you set exact point-size cutoffs instead, which is more reliable for a document whose body size you already know from a PDF inspector.

What does the two-column fix actually do?

It checks whether a page's lines cleanly split into a left group and a right group with a clear gutter between them. If so, it reads the entire left column top-to-bottom before moving to the right column, instead of the left-to-right order the raw text stream would otherwise produce.

How reliable is the table detection?

It looks for several consecutive lines that each split into the same number of column clusters, based on the gap threshold you set. Clean, whitespace-separated grids convert well; ruled tables with no real gaps, merged cells, or tables with wrapped cell text usually need a manual pass afterward.

Why would a page turn into an image?

Some PDFs are scans with no real text layer, just a picture of a page. If a page yields almost no extractable text, the tool renders that page as an image and embeds it in the Markdown, so you can see the content was there instead of getting an empty or garbled section.

How is a repeated header or footer identified?

The tool scans every page first, collects the text sitting in the top and bottom margin zones, and flags anything that shows up on most of the pages — a running book title, a chapter name, or a footer line. Only that flagged text is dropped; one-off content near the margins is left alone.

Is anything uploaded to a server?

No. The PDF you add is parsed and converted locally in your browser using pdf.js — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
