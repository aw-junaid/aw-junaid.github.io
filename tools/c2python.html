✦ How This Tool Works

Is this a full C compiler front-end?

No — it's a rule-based, pattern-matching converter, not a full parser or semantic analyzer. It handles common constructs (functions, loops, conditionals, structs, arrays, printf/scanf) reliably, but it can't reason about types the way a compiler does. Always review the output, especially anything flagged in the Diagnostics tab.

How are pointers handled?

Python has no pointers or address-of operator, so * and & are stripped from declarations and expressions when "Strip pointer/address-of symbols" is on. Every occurrence is logged as a diagnostic, because the actual semantics — pass-by-reference for mutable objects, pointer arithmetic, double indirection — need a human to verify.

What happens to malloc(), free(), and realloc()?

Python's garbage collector manages memory automatically, so there's no direct equivalent. Depending on the "malloc() handling" setting, a simple malloc(n * sizeof(type)) pattern is rewritten as a pre-sized list, or commented out with a TODO. free() calls are removed with an explanatory comment. Both are always reported in Diagnostics.

How are structs converted?

A struct Name { ... }; becomes a Python class Name: with an __init__ method, and each field becomes a self.field assignment with a type-appropriate default. This gives you a starting point for a dataclass-style object — it doesn't replicate struct memory layout or padding, which don't exist in Python.

What does the Line Mapping and Diagnostics tab show?

Line Mapping lines up each original C line against the Python it produced, so you can trace exactly where a translation came from. Diagnostics is a plain-language report of constructs a rule-based converter can't safely resolve — pointers, manual memory management, macros, goto, unions, function pointers, and multi-dimensional arrays — each with the line number to check.

How is switch/case converted?

Since Python has no switch statement, each case becomes an if/elif comparison against the switch expression, default becomes else, and break; lines are dropped since they're no longer needed. Fallthrough between cases (no break) isn't automatically replicated — it's flagged for manual review.

Can I convert multiple files at once?

Yes — upload or drag in several .c files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .py files into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
