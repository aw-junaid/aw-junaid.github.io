PDF Compressor

A scanned contract, a photographed receipt, an export from a phone camera app — and suddenly your "one page" PDF is 18MB and bouncing off an email attachment limit. This tool inspects exactly what's bloating the file (almost always the embedded images), recompresses or downsamples them, strips dead weight, and — if you set a target size — keeps retrying until it fits. Nothing leaves your browser.
Why PDFs balloon in size

Scanner and camera apps routinely embed images at full sensor resolution and near-lossless quality — a single photographed page can carry a 6–15MB JPEG doing the work of a 300KB one. Add uncompressed object tables, leftover revision data, and no object-stream packing, and a five-page document can outweigh a short film clip. This tool targets each of those causes directly instead of just re-zipping the file.

✦ How This Tool Works

Where does the size actually go?

In almost every oversized PDF, embedded raster images account for the overwhelming majority of the file. This tool scans every image XObject in the document and shows you what share of the total file they make up before you compress anything.

Does it re-encode text and vector graphics?

No — real text and vector drawing stay exactly as they are (still selectable and sharp at any zoom) unless you turn on full-page rasterization. Only raster image data is recompressed, which is where the actual bloat lives.

What does "Max image resolution" actually change?

It caps the longest side of each embedded image in pixels before recompression. A camera photo saved at 4000px wide is almost always far more detail than a printed or on-screen page needs — capping it is usually the single biggest size reduction available.

When should I use page rasterization?

Only for PDFs that are already just photos of pages with little real, selectable text — think a phone-scanned form. It re-renders each page as one compressed image, which shrinks aggressively but permanently removes text selection and searchability.

How does the target size option work?

If you set a target, the tool compresses at your chosen quality, checks the result, and — if it's still too big — automatically retries at a lower quality (down to a 20% floor) up to five times, logging each attempt so you can see what it took.

Is anything uploaded to a server?

No. Every PDF you load is scanned and compressed locally in your browser using pdf-lib, pdf.js, and canvas re-encoding — nothing is sent anywhere. Reload the page and everything is cleared except your settings.
