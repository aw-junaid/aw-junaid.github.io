✦ How This Tool Works

How is a nested JSON object turned into columns?

Flattening walks each record and joins nested keys with your separator, so {"address":{"city":"Lahore"}} becomes a single address.city column. Turn flattening off to keep the whole nested object as one JSON-text cell instead.

What's the difference between the three array modes?

Join puts every item in one cell, separated by your delimiter — good for tags or short lists. Expand creates tags[0], tags[1]… columns up to your column limit — good when position matters. Explode repeats the parent row once per array item — good for invoice line items or order products, where each item really deserves its own CSV row.

My records don't all have the same keys — what happens?

With "Union of keys across all rows" on, every key seen in any record becomes a column, and rows missing that key just get an empty cell — this is the usual behavior for real-world API exports where optional fields are only present sometimes. Turn it off to use only the first row's keys and silently drop the rest.

Why would I need the root path field?

Many APIs wrap the actual rows inside an envelope, e.g. {"meta":{...},"data":{"items":[...]}}. Set the root path to data.items to convert just that array. Left blank, the tool auto-detects the root array or the first array-valued property it finds.

Why does Excel show garbled accented characters?

Excel assumes plain CSV files are in the system's local encoding unless a UTF-8 byte-order mark (BOM) is present. Enable "UTF-8 BOM" so double-clicking the downloaded .csv opens correctly in Excel; other tools that already expect clean UTF-8 can leave it off.

Can I convert multiple JSON files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .csv files into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
