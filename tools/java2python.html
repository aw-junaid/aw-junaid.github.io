✦ How This Tool Works

Is this a real compiler-grade translation?

No — it's a best-effort, pattern-based converter that runs entirely in your browser. It handles the syntax that shows up in the vast majority of real-world Java: classes, loops, conditionals, collections, exceptions, and common String/Collection methods. Anything ambiguous is left in place and flagged in Conversion Notes rather than guessed at silently.

How are ArrayList, HashMap, and HashSet handled?

With "Map Java collections" on, declarations like List<String> or new HashMap<>() become Python's list/dict/set literals, and common calls are rewritten: .add() → .append(), .put(k, v) → [k] = v, .get(k) → [k], .size() → len(...).

What happens to static members and checked exceptions?

Python has neither concept exactly. Static fields/methods are moved to class scope, and throws clauses are dropped from the signature — both are logged to Conversion Notes so you know exactly which lines to review by hand.

What does switch/case become?

Choose "if/elif chain" for maximum compatibility with any Python 3 version, or "match/case" for Python 3.10+'s structural pattern matching, which reads closer to the original switch statement.

Do I get type hints?

With "Add PEP 484 type hints" on, common Java types (int, String, boolean, List<T>, Map<K,V>, custom classes) are mapped onto parameter and return annotations so the converted signature stays self-documenting.

Can I convert multiple files at once?

Yes — upload or drag in several .java files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .py files into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
