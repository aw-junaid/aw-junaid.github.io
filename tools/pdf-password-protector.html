✦ How This Tool Works

What's the difference between the two passwords?

The open (user) password is required just to view the file — without it, the document won't open at all. The owner password lets the file open freely but is needed to change the permission restrictions (printing, copying, editing) in compliant PDF software. Set either one alone, or both together for maximum control.

Why is an owner password generated automatically sometimes?

Permission restrictions in the PDF spec are only meaningful when an owner password exists — otherwise there's nothing stopping someone from removing them. If you restrict any permission but leave the owner password blank, this tool generates a strong random one behind the scenes so your restrictions actually take effect.

AES-128 vs AES-256 — which should I choose?

AES-256 is stronger and recommended when the recipient uses modern software (Acrobat X / 2017+, most current readers). AES-128 has broader compatibility with older PDF readers and some archival or scanning systems. If you're unsure who's opening the file, AES-128 is the safer default for compatibility.

Are permission restrictions actually enforced?

They're enforced by compliant PDF readers (Acrobat, Preview, most browsers) reading the permission flags in the encryption dictionary. They are a deterrent, not unbreakable — determined users with certain tools can strip permission-only restrictions. For content you truly cannot risk being copied or printed, the open password is the meaningful control.

Can I protect several PDFs at once with the same settings?

Yes — queue multiple files, set your passwords and permissions once, and click "Protect & Export". Each file is encrypted independently in your browser and downloaded individually, or bundled into a single .zip if you choose that output mode.

Is anything uploaded to a server?

No. Files are read, encrypted, and packaged entirely client-side in your browser — nothing is sent anywhere. Reload the page and the queue is cleared, except your settings, which are remembered for next time. Because of this, if you forget the password you set, there is no recovery — store it somewhere safe.
