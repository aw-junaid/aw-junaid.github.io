✦ How This Tool Works

What problem does this actually solve?

Checking a single domain's registrar or expiration is easy enough by hand, but keeping track of a whole portfolio — or chasing down who to contact about abusive traffic from an IP — usually means opening a dozen browser tabs across different registries. This tool queries them in one batch, flags anything expiring soon, and exports the results so the check becomes repeatable instead of a manual chore.

What is RDAP, and why not classic WHOIS?

Classic WHOIS is a plain-text protocol on port 43 that browsers cannot query directly, with output formatting that varies by registry. RDAP (Registration Data Access Protocol) is its IETF-standardized successor — the same registration data returned as structured JSON over regular HTTPS, which is exactly what makes a browser-based lookup like this possible without a server in between.

Why are some contact fields empty or missing?

Since GDPR took effect, most registrars redact registrant, admin, and technical contact details from public RDAP responses by default, replacing them with the registrar's own proxy contact or leaving them out entirely. The "Flag privacy-redacted contacts" setting marks entities with no visible name, organization, or email so it is obvious the data is being withheld rather than genuinely missing from the registry.

Is the availability check reliable enough to register on?

A 404 from RDAP usually means a domain is not registered, but not every TLD has full RDAP coverage yet, and a domain can be in a grace or redemption period that still returns a record. Treat a "likely available" result as a strong hint to go check with a registrar or registry directly, not as a guarantee the name is yours for the taking.

Why does batch mode pace itself instead of firing all requests at once?

Public RDAP endpoints will throttle or temporarily block a client that sends a burst of requests too quickly. The delay-between-requests and max-concurrent-requests settings spread a portfolio-sized batch out over a few extra seconds, which is the difference between a batch that completes cleanly and one that starts returning errors partway through.

Is anything sent to a server?

Yes, by necessity: unlike a pure calculator, a registration lookup has to ask a registry somewhere for the answer. Each domain, IP, or ASN you enter is sent as an RDAP query to rdap.org (or the custom RDAP base you configure), which routes it to the right authoritative registry. No other part of this page — settings, history, or anything you have not explicitly looked up — is sent anywhere.
