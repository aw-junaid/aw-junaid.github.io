✦ How This Tool Works

What counts as "lenient" JSON, and why allow it?

Real config files — tsconfig.json, VS Code settings, hand-edited API fixtures — are usually JSONC: they contain // comments, /* */ blocks, and trailing commas that break JSON.parse. This tool parses those forms directly instead of asking you to clean the file by hand first, then strips them on the way out.

How are duplicate keys handled?

Strict JSON doesn't forbid repeating a key in the same object, but parsers disagree on what to do with it. Choose keep last (matches JSON.parse's default behavior), keep first, or error to fail loudly — and every duplicate found is listed on the Warnings tab either way.

Why would I strip null values or empty containers?

APIs and ORMs often serialize every field, even unset ones, as null, {}, or []. If your consumer treats "absent" and "null" the same way, removing them shrinks payloads with no loss of meaning — each removal is logged as a warning so you can double-check nothing important was dropped.

What is NDJSON output for?

Newline-delimited JSON puts one minified object per line instead of one giant array. It's the format expected by log shippers, Kafka/Kinesis consumers, and streaming import tools that read a record at a time rather than parsing the whole file into memory.

How is the gzip size measured?

Rather than estimate, this tool runs the minified output through your browser's native CompressionStream gzip implementation and reports the real compressed byte count — the same algorithm your web server or CDN would apply over the wire.

What's the difference between the wrap modes?

Plain JSON is the minified data alone. JS const and CommonJS wrap it as an importable module for bundlers that prefer import data from './data.js' over a fetch. Base64 encodes it as a single string, handy for embedding inside another JSON field, a URL parameter, or a data attribute.

Does rounding numbers change the data?

Yes — deliberately. Computed values like 19.999999998 or 0.1 + 0.2 floating-point noise carry no real information past a few decimals. Rounding is opt-in and off by default so it never silently touches data you didn't ask it to.

Can I minify multiple files at once?

Yes — upload or drag in several files and each becomes a tab above the editor. "Download All (.zip)" minifies every loaded file with your current settings and bundles the results into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
