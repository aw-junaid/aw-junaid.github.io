✦ How This Tool Works

How does type inference work?

The converter walks the parsed JSON value by value: primitives map to string/number/boolean, arrays infer an element type from every item they contain, and objects become interfaces built from their own keys. Numbers past Number.MAX_SAFE_INTEGER get flagged for a possible bigint.

What's the difference between hoisted and inline nested objects?

"Extract into named interfaces" pulls every nested object out into its own declaration named after its key (e.g. a profile key becomes a Profile interface), which is easier to reuse and read. "Inline" keeps the shape written directly inside the parent property's type instead.

How are optional properties detected?

With a single JSON sample, a property is optional if you enable "infer optional from null values" and it was observed as null. With multiple samples and merging turned on, a property is optional whenever it's missing from at least one of the uploaded samples — the same logic used to merge array-of-object shapes.

What does Record<string, T> detection do?

Objects that look like lookup maps — many keys, all pointing to the same value type — are hard to model as a fixed interface. When the key count passes your threshold and every value shares a type, the tool emits Record<string, T> instead of listing every key individually.

Can I merge several JSON samples into one shape?

Yes — upload 2 or more files and turn on "merge multiple uploaded samples." The tool treats each file as one observation of the same object, unions their keys, and marks anything not present in every sample as optional, which is useful for API responses that vary slightly between calls.

Does strict mode matter if my input isn't valid JSON?

With strict mode on, only RFC 8259-valid JSON is accepted and parse errors report a line/column. Turning it off lets the tool tolerate common near-JSON issues — trailing commas, unquoted keys, single-quoted strings, and comments — which is handy when pasting JS object literals or JSONC config files.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
