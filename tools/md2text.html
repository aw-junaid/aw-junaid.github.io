✦ How This Tool Works

What problem does this actually solve?

Markdown renders fine in a browser or editor, but a lot of destinations don't render it at all — plain-text email clients, SMS gateways, ATS resume parsers, terminal output, and changelog diffs all just show you the raw asterisks and hashes. This tool strips the syntax while giving you control over what happens to links, tables, and images so the result still reads cleanly.

Why does link handling have four modes?

"Text only" is cleanest for a resume or email body. "Text + URL" keeps the destination visible for SMS or plain-text where a reader can't click. "Footnote" numbers every link and lists the URLs at the end — useful for longer documents where inline URLs would clutter the flow. "URL only" is for cases where the link text itself doesn't matter.

How does table flattening work?

"Space-aligned columns" measures each column's widest cell and pads every row to match, so the table still reads as a grid in a monospace font. "Pipe-separated" keeps the raw | a | b | rows without the header separator line. "CSV" swaps pipes for commas. "Drop" removes the table entirely, useful when the destination can't display tabular data at all.

What does the character limit + wrap width solve?

Wrap width reflows paragraphs to a fixed column count, which is how plain-text email and old-school terminal output stays readable without a renderer. The hard character limit is built for SMS or any character-capped field — set it to 160 and choose whether the tool truncates with an ellipsis or just warns you that the text is over budget.

What shows up in the Removed-content Diff tab?

It replays your original Markdown with every stripped character struck through in place, so you can see exactly what the converter removed — asterisks, hashes, link brackets, fence markers — without losing the surrounding context. It's the fastest way to confirm the tool didn't eat something you wanted kept.

Can I convert multiple files at once?

Yes — upload or drag in several .md files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .txt files into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
