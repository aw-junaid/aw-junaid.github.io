✦ How This Tool Works

How do I write a page range?

Use comma-separated numbers and dashes, like 1-3,5,8-10. Leave the field blank (or type "all") to include every page from that file. Ranges are 1-indexed and clamp automatically to the file's real page count.

What do blank separator pages do?

"Between files only" inserts one blank page after each file except the last, so you can tell where one document ends and the next begins. "After every file" also adds one after the final document — handy when preparing a stack for duplex printing.

How does page size normalization work?

"Uniform to first document" scales every later page to fit within the dimensions of the very first page, preserving its aspect ratio. "Scale to fit A4/Letter" does the same against a fixed target size. Pages are never stretched or cropped — just scaled down or up to fit.

Can I reorder or rotate individual files?

Yes. Each file in the list has up/down arrows to change its position in the merge order, plus its own page range and rotation (0°/90°/180°/270°, added on top of any rotation the page already has).

Will this work on password-protected PDFs?

Files that are genuinely encrypted with an open password can't be parsed client-side and will be skipped with a warning in the Log tab. PDFs with only owner-level restrictions (print/copy locks) usually still merge fine.

Is anything uploaded to a server?

No. Every file you add is read and merged locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
