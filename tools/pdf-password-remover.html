✦ How This Tool Works

Do I need the password?

Only if the file demands one just to open it. Many "protected" PDFs only restrict printing, copying, or editing and open fine with no password — this tool detects that automatically and strips those restrictions without asking you for anything. If a real open-password is set, you'll need to know it; there's no way to guess or crack it here.

What's the difference between the two unlock methods?

Direct unlock rebuilds the file's internal structure without its encryption, keeping your original text, fonts, and vector graphics fully intact — it works whenever the file doesn't actually require a password to open. Rebuild-by-rendering redraws every page as a flattened image inside a new file instead; it's the fallback used whenever a real password is required, since a password-protected page's content can't be copied out directly. It also doubles as a "deep clean" for files with stubborn restrictions.

Why would rebuilt pages lose selectable text?

Rendering a page to an image captures exactly what's visible, but it doesn't preserve the underlying text objects — so the result is a picture of the page, not the page itself. It still prints, displays, and scrolls correctly; it just can't be searched or have its text copied afterward.

What happens if a page fails partway through?

Set your preferred behavior in "If a Page Fails to Process": skip it and keep going, drop in a blank placeholder so page numbers still line up, or stop the whole job so you can investigate. Every failure is written to the Log tab with the page number and reason.

What does the "Verify" option actually check?

Before the Download button unlocks, the tool re-opens the file it just produced and confirms every page loads without errors — catching a corrupted or incomplete result before it ever reaches your disk.

Is anything uploaded to a server?

No. The file and password you enter are processed entirely in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
