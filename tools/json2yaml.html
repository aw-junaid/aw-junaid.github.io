✦ How This Tool Works

Block, flow, or auto — which collection style should I pick?

"Block everywhere" produces classic indented YAML for both objects and arrays. "Flow everywhere" writes JSON-like { } / [ ] on single lines throughout. "Auto" keeps outer levels in block style and switches to flow once nesting passes the depth you set — handy for keeping short leaf arrays compact while top-level structure stays readable.

What does anchor de-duplication do?

When the same object or array appears more than once in your JSON (by reference), enabling anchors writes it once with an &anchor and reuses it elsewhere with *alias, shrinking the output. It's off by default because most JSON has no shared references and the option only matters when you built the object graph yourself before stringifying.

What's the difference between the two quoting settings?

"String quoting style" only decides which quote character js-yaml reaches for when a string actually needs quoting (special characters, leading zeros, reserved words). "Force-quote all strings" overrides that and wraps every string value in quotes regardless of whether YAML would require it — useful for diffing against a strict YAML linter.

What does "Array root → multi-document" do?

If your JSON's top level is an array of objects — a common shape for exported records or NDJSON-style data — this turns each array item into its own YAML document separated by ---, instead of one long block-sequence.

Can I convert multiple files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .yaml files into one archive.

What does Strict Mode change?

With Strict Mode on, any parse error stops conversion and shows the exact line and column of the problem. With it off, the parser still reports the error but the editor won't visually flag partial output — useful when iterating on a file you know is incomplete.

What do Presets and Export/Import Config do?

Presets instantly apply a bundle of settings tuned for a use case (human-readable, Kubernetes manifests, compact flow-style, strict quoting). Export Config saves your exact settings as a JSON file your team can share and re-import for consistent output.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
