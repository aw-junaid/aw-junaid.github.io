✦ How This Tool Works

Why convert an IP to a decimal integer at all?

Storing an IP as a single integer instead of a string is faster to index, faster to compare, and makes "is this address inside this range" a simple numeric comparison — which is why databases, CDNs, and firewall rule engines built on integer ranges lean on this form instead of raw text.

Why do some tools show a negative number for my IP?

An IPv4 address only needs 32 bits, but some older languages and database columns (Java's int, MySQL's signed INT) store that value as a signed 32-bit integer. Any address ≥ 128.0.0.0 has its high bit set, so it reads as negative under two's-complement — the number is correct, it's just being interpreted with a sign.

What's the difference between big-endian and little-endian here?

Big-endian (network byte order) is the standard used by INET_ATON, ip2long, and TCP/IP itself — the first octet is the most significant byte. Little-endian reverses that byte order, which is how x86/ARM CPUs store integers in memory internally; it only matters when you're packing/unpacking raw bytes yourself, e.g. with C's struct or a raw socket.

How is an IPv6 address represented as a decimal?

IPv6 is 128 bits, well beyond a normal integer column, so it's shown here as one full BigInt decimal, as 32 hex digits, and split into a high/low pair of 64-bit words — the split form matches how it's commonly stored as two BIGINT columns when a native inet/binary(16) type isn't available.

Are the code snippets guaranteed correct for my exact setup?

They're written for the common case of each language/DB and are a solid starting point, but ORM configuration, column types, and PHP's 32-bit vs 64-bit build behavior can all change the exact result — treat them as a template to adapt, not a drop-in guarantee.

Is anything sent to a server?

No. Every conversion — IP-to-decimal, decimal-to-IP, byte-order inspection, and the CIDR range calculation — runs entirely in your browser. Your draft input and settings only persist in this browser's local storage, and nothing is uploaded anywhere.
