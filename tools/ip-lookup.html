✦ How This Tool Works

What problem does this actually solve?

Abuse reports, firewall logs, and server migration checklists all hand you raw IP addresses with no context. This tool bulk-resolves them to geolocation, ISP, and network ownership, flags anything internal or reserved before you waste a lookup on it, and gets the results into a CSV or ticket-ready format fast.

Why flag private and reserved ranges locally?

Addresses like 10.x, 172.16–31.x, 192.168.x, loopback, link-local, and CGNAT ranges will never resolve to a real-world location — sending them to a geolocation API just burns your request quota for a useless answer. Detecting these entirely in your browser catches them instantly and for free.

Where does the geolocation data come from?

Public IP lookups call a third-party geolocation API directly from your browser. Accuracy for city-level data varies by provider and by ISP — treat it as a strong starting point for triage, not a precise physical address.

What does the CIDR/Subnet Calculator do?

Enter any IPv4 address with a CIDR prefix (like 192.168.1.0/24) and it works out the network and broadcast addresses, the usable host range, total host count, subnet mask, and wildcard mask — entirely offline, no lookup required. Handy for firewall rules, VLAN planning, and sanity-checking log entries.

Can I look up more than one IP at once?

Yes — paste one address per line, or drop in a raw log file and IPv4/IPv6 addresses are extracted automatically. Requests run sequentially with a configurable delay between them so you don't trip the geolocation provider's rate limit on large batches.

Is anything saved or sent anywhere else?

The page itself runs entirely in your browser. The only outbound traffic is the geolocation request for each public IP you look up, sent straight from your browser to the lookup provider — nothing is proxied through or stored on this site, and your list resets when you leave the page.
