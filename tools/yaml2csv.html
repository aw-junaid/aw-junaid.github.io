✦ How This Tool Works

How do I choose which part of the YAML becomes rows?

Set the "Root path" to a dot-notated key like spec.services to point at an array of records. Leave it blank and enable auto-detect to let the tool find the first array of objects on its own — useful when you don't know the exact shape yet.

What does multi-document handling do?

YAML files can contain several documents separated by ---, like a stack of Kubernetes manifests. "Merge root arrays" concatenates each document's matched array into one table; "Each document = one row" treats every manifest as a single flattened record — handy for exporting a resource list.

How are nested objects and arrays flattened?

Nested objects are expanded into dotted columns, like owner.id, up to the max flatten depth you set — beyond that, the remaining structure is stored as JSON in one cell. Arrays inside a row can be joined into one cell, split into indexed columns, or kept as a JSON string, depending on the array field mode you pick.

What do the Table Preview and Column Schema show?

Table Preview renders your CSV as an actual scrollable table so you can sanity-check the shape before downloading. Column Schema lists every detected column with the value types seen in it and how many rows populate it — useful for catching a column that's mixing numbers and text.

Can I convert multiple YAML files at once?

Yes — upload or drag in several .yaml/.yml files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .csv files into one archive.

What does Strict Mode change?

With Strict Mode on, malformed YAML stops conversion and shows the parser's full error detail, including the line and column where it failed. With it off, the same error is still shown, but the input editor won't be visually flagged.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
