✦ How This Tool Works

How does it decide between a plain field, a pointer, and any?

The converter samples every occurrence of a key across sibling objects (e.g. every item in an array). If the type is consistent everywhere, it's typed plainly; if it's sometimes null and pointer-nullability is on, it becomes *T; if it holds genuinely different JSON types across samples, it falls back to any (Go has no union types) and gets flagged for review.

Why are struct fields capitalized differently from my JSON keys?

encoding/json can only see exported fields, so every generated field name is PascalCase regardless of the source key's casing. The original key is preserved exactly via a json:"originalKey" tag, so marshaling round-trips correctly without you tracking the mapping by hand.

Why pointers instead of just omitempty?

omitempty alone can't distinguish a field that's genuinely zero (e.g. 0, "") from one that was never sent. When a field is seen as both a real value and null across samples, a pointer (*string, *int64, …) lets you check if f.Field != nil to tell "absent" from "zero" — the classic Go trade-off this tool applies automatically.

How are duplicate/near-duplicate object shapes handled?

With "Deduplicate structurally identical structs" on, two JSON objects (even at different paths) that produce the same field names and types are collapsed into a single generated struct instead of emitting near-identical structs twice — common in API responses with repeated address/contact/money shapes.

Does it detect dates, UUIDs, and enums automatically?

Yes, each independently toggleable. ISO 8601 strings become time.Time, which encoding/json parses as RFC3339 with zero extra code; RFC 4122 strings become uuid.UUID from github.com/google/uuid; and string fields with a small, repeated set of values across an array (e.g. a status field) can be promoted to a generated type StatusEnum string with named constants.

Can I convert multiple JSON files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .go files into one archive.

What do the built-in presets change?

API Response favors json tags, omitempty, pointer nullability, and time.Time. Strict/Validated adds validate tags and a generated Validate() method with no omitempty. Config File turns off pointer nullability and switches to yaml tags. Database Model adds db/bson tags for nullable columns.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
