✦ How This Tool Works

Reflow, Preserve Layout, or Raw Stream — which one?

Reflow is right for reading a report or article — it rejoins wrapped lines into paragraphs. Preserve Layout keeps line breaks close to the original, which matters for forms, invoices, and tables where position carries meaning. Raw Stream dumps every text fragment pdf.js reports, useful for debugging odd extraction results.

How does repeated header/footer stripping work?

After every page is extracted, the tool looks for lines near the top or bottom of a page that repeat across most other pages — a running title, a document code, a page number — and removes them. It only strips lines that repeat; a one-off heading is left alone.

Why would I need OCR if the PDF already has "text" in it?

Some PDFs are just scanned images with no underlying text layer at all, so normal extraction returns almost nothing. Turning on OCR renders those pages as images and reads the characters visually, in your browser, only for pages that fall below the character threshold you set.

What do the margin sliders actually exclude?

Each slider is a percentage of the page's height or width measured from that edge. Text positioned inside that band — say the top 8% of every page — is dropped before reflow even runs, which is a more reliable fix than pattern-matching when a header changes wording page to page.

What's the difference between the export formats?

Plain text and Markdown are for reading or pasting elsewhere, with Markdown adding page headings. JSON gives you an array of page objects — useful for feeding into another script. CSV gives one row per page with the page number and its text, handy for spreadsheets.

Is anything uploaded to a server?

No. The file you add is read, parsed and (optionally) OCR'd locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
