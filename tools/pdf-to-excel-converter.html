PDF to Excel Converter

Invoices, bank statements, and vendor reports almost always arrive as PDFs — and almost never as usable spreadsheets. Retyping rows by hand introduces typos in totals, breaks decimal places, and loses hours you don't have. This tool detects the tables on every page, lets you tune exactly how columns and numbers are read, and exports a real, formula-ready .xlsx or .csv — entirely in your browser.
The problem this solves

Copy-pasting a PDF table into Excel usually collapses every column into one, turns "1,234.56" into text, drops leading zeros, and merges wrapped line items into the row above. This tool reads each page's actual text positions, reconstructs rows and columns from the whitespace between them, and classifies each cell as a number, date, or currency amount before it ever reaches the spreadsheet — so totals stay totals and dates stay sortable.

✦ How This Tool Works

How does it find tables without an AI model?

Every letter in a PDF has an exact x/y position. This tool groups text into rows by shared vertical position (Row grouping tolerance), then splits each row into columns wherever the horizontal gap between words exceeds the Column gap threshold — the same visual cue a person's eye uses to read a table.

Why does the column gap threshold matter so much?

Set it too low and normal word spacing gets treated as a new column, fragmenting a single sentence across cells. Set it too high and separate columns merge into one. Bank statements and dense reports usually need a smaller value than a simple one-page invoice.

How are numbers and currency handled?

Cells matching a numeric pattern are written as real Excel numbers, not text — so totals can be summed directly. Currency symbols are stripped first, accounting-style parentheses become negative values, and the number format setting controls whether "1.234,56" or "1,234.56" is read correctly for your source locale.

What happens to line items that wrap onto a second line?

A wrapped description often lands as a short row with no numeric cells beneath the row it belongs to. With "Merge wrapped line items" on, such rows are folded back into the row above instead of appearing as a broken, mostly-empty row in the output.

One sheet per page, or one combined sheet?

Turn on "One sheet per PDF page" for documents like multi-page bank statements where each page is its own self-contained table. Leave it off for reports where the same table continues across pages and should end up as one continuous sheet.

Is anything uploaded to a server?

No. Every PDF you load is parsed and converted locally in your browser — nothing is sent anywhere, which matters most for exactly the financial and business documents this tool is built for. Reload the page and everything is cleared except your settings.
