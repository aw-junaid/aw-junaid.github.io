✦ How This Tool Works

What problem does this actually solve?

Device labels, ARP tables, DHCP leases, and vendor docs all format MAC addresses differently, and identifying an unknown device on a network usually starts with its manufacturer. This tool validates any common notation, converts between them, resolves the OUI to a vendor, flags special-purpose and randomized addresses, and audits whole inventory lists at once.

What is the U/L bit, and why does it matter?

The second-lowest bit of the first octet marks whether an address was assigned by the IEEE to a manufacturer (universal) or set by software (local). Since 2020, iOS, Android, and Windows all default to generating a locally-administered address per network to prevent tracking — seeing this bit set on a device that should have a factory address is the quickest way to spot a randomized MAC.

How accurate is the built-in vendor database?

It's a curated offline list covering common consumer, enterprise, and virtualization manufacturers — enough for most day-to-day lookups without a network request. The full IEEE registry has tens of thousands of entries, so for anything the offline list doesn't recognize, enable the online fallback to query a live vendor API instead.

What does the EUI-64 conversion actually compute?

Per RFC 4291, the 24-bit vendor and 24-bit device portions are split apart, the fixed bytes FF:FE are inserted between them, and the U/L bit is flipped — turning a 48-bit MAC into a 64-bit interface identifier. That identifier is what a device historically used to self-assign the host portion of an IPv6 address via SLAAC.

Why generate a random MAC in a "locally administered" range?

Setting the U/L bit guarantees the generated address can never collide with a real IEEE-registered vendor block, which is the standard, collision-safe way to hand out addresses for VMs, containers, and lab equipment without reserving a real OUI.

Is anything sent to a server?

No, with one exception: the online vendor lookup (built-in toggle or the standalone utility card) is opt-in and calls a third-party API (api.macvendors.com) to resolve an OUI. Everything else — parsing, validation, format conversion, EUI-64 math, batch auditing — runs entirely in your browser. Your draft and settings only persist in this browser's local storage.
