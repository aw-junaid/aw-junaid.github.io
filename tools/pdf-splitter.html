✦ How This Tool Works

Which split mode should I use?

Use Custom ranges when you know exactly where each chapter or section starts and ends. Fixed interval is fastest for chopping a long scan into equal batches. Breakpoints suits a stack where you only know where each document starts. Extract pulls a handful of pages out; Remove deletes a handful and keeps everything else.

How do I write a page range?

Use comma-separated numbers and dashes, like 1-3,5,8-10. Ranges are 1-indexed and clamp automatically to the source file's real page count.

What does "restart numbering per file" mean?

With it on, every output file's stamped page numbers start fresh at 1. Turn it off to keep each page's number as it was in the original document — useful when the parts will later be reassembled or cross-referenced.

What happens with more than one output file?

Each output is listed individually with its own download button, and — if "Bundle into a ZIP" is on — a single "Download" button gives you every file at once in a .zip. A single output always downloads as a plain .pdf.

Will this work on password-protected PDFs?

A file genuinely encrypted with an open password can't be parsed client-side and will show an error instead of a page count. PDFs with only owner-level restrictions (print/copy locks) usually still split fine.

Is anything uploaded to a server?

No. The file you add is read and split locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
