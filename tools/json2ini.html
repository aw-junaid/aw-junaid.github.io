✦ How This Tool Works

How do JSON objects become INI sections?

Each top-level key whose value is an object becomes a [section] header, and its properties become key/value lines underneath. Objects nested deeper than that are flattened into a single dotted key (e.g. database.credentials.user) using the delimiter you set, since INI itself only supports two real levels: sections and keys.

Why does JSON need a real-world array strategy?

INI has no native array type, so this is the lossiest part of any JSON→INI conversion. Pick "Repeat key" for parsers that accumulate repeated keys into a list, "Indexed keys" or "PHP-style" for PHP's parse_ini_file(), "Comma-joined" for simple env-style configs, or "JSON string" to preserve the array exactly and decode it back out later.

What happens to an array of objects?

With "Array-of-objects → indexed sections" on, a key like "servers": [{...}, {...}] produces [servers.0] and [servers.1] sections — the closest INI equivalent to TOML's array of tables. Turn it off and the whole array is instead JSON-encoded into a single value, with a note in the Warnings tab.

What does the Section Map and Warnings tab show?

Section Map lists every section (or the global block) with its resulting keys and value types, so you can confirm nothing landed where you didn't expect. Warnings flags real data-loss risks: two different JSON paths flattening to the same key (last one wins), or mixed-type arrays that had to be JSON-encoded because the current array strategy can't represent them.

Why would I disable sections entirely?

Some INI-like formats used by env-style tooling and legacy config loaders don't support [section] headers at all. "Flatten everything — no sections" joins the full path of every value with your delimiter into one flat, section-free block instead.

Can I convert multiple files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .ini files into one archive.

What does Strict Mode change?

With Strict Mode on, invalid JSON or a non-object root value (INI can't represent a top-level array or scalar) stops conversion and shows a clear error. With it off, the same problems are still reported, but the input editor won't be visually flagged.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
