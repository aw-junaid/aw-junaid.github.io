✦ How This Tool Works

How does "Grouped" property sorting decide order?

Declarations are bucketed into five groups — positioning, display/box model, typography, visual (backgrounds, shadows, borders), then animation/transform — and each rule's declarations are reordered into that sequence. Properties that don't match any group fall through to a final "everything else" bucket, keeping the output predictable across an entire stylesheet.

Is it safe to remove vendor prefixes?

This tool only removes a prefixed declaration (like -webkit-transform) when the same rule already defines the unprefixed version (transform). A prefixed property with no standard equivalent, such as -webkit-line-clamp, is always left alone, since deleting it could silently break the styling.

What's the difference between Formatted and Minified?

Formatted CSS follows your style settings — indentation, brace position, sorting — for something you'd commit to a repo. Minified CSS always compresses to the smallest safe output regardless of those style toggles (no whitespace, shortened hex colors, stripped zero-units) while still respecting your cleanup choices like deduping and empty-rule removal.

Why do zero values sometimes keep their unit?

Stripping the unit from a zero length (0px → 0) is safe because CSS treats a bare zero as a valid length. Zero time values like 0s are left untouched, since the CSS specification requires a unit on time values even when the number is zero.

What happens to duplicate declarations and selectors?

With "Remove duplicate properties" on, if a rule sets the same property twice, only the last value (the one the browser would actually apply) is kept. Separately, "Merge duplicate selectors" combines two rule blocks that share the exact same selector text into a single block, preserving the original declaration order.

What is the Rule Map for?

Before trusting a large formatted stylesheet, it helps to see its shape at a glance. The Rule Map lists every selector and at-rule (@media, @keyframes, @font-face, and so on) the conversion produced, indented to show nesting, so you can quickly confirm nothing was lost or misplaced.

How does mobile-first @media sorting work?

When enabled, top-level @media (min-width: …) blocks are reordered from the smallest breakpoint to the largest. Media queries that aren't a simple min-width check, or other at-rules, keep their original relative position.

Can I format multiple stylesheets at once?

Yes — upload or drag in several .css files and each becomes a tab above the editor. "Download All (.zip)" formats every loaded file with your current settings and bundles the resulting .css files into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
