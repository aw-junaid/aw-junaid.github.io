✦ How This Tool Works

How does type inference work without a Python type checker?

The converter reads literals, arithmetic, and any type hints you've written (x: int, -> List[str]) to guess a C++ type per variable. When it truly can't tell, it either falls back to auto (if that setting is on) or emits the default integer/float/string type you've configured, and logs a note so you can double-check it.

Why does it flag things instead of just converting them?

Python and C++ solve some real-world problems differently by design — duck typing, generators, multiple inheritance, *args, and dynamic re-typing of a variable don't have a clean 1:1 C++ equivalent. Rather than silently emitting something that compiles but behaves differently, the tool flags these constructs in the Conversion Notes tab for manual review.

How are Python containers mapped to STL?

Each container type has its own dropdown: lists can become std::vector, std::array, or std::deque; dicts become std::unordered_map or ordered std::map; sets and tuples work the same way. Pick ordered variants when you need Python's dict-insertion-order or sorted-key guarantees preserved.

What's the difference between the ownership modes?

Value semantics keeps class instances on the stack with RAII cleanup — closest to how small Python objects behave, but doesn't model shared references. unique_ptr models single ownership with move-only transfer; shared_ptr models Python's reference-counted gc behavior most closely, at the cost of atomic refcounting overhead.

Does it generate the right #include list automatically?

Yes, when "Auto-detect required #includes" is on — it scans the generated C++ for usages like std::vector, std::string, or std::optional and only includes headers actually needed, keeping compile times down. Turn it off to manage includes yourself.

Can I convert multiple files at once?

Yes — upload or drag in several .py files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .cpp files into one archive.

What do the built-in presets change?

Modern C++17/20 favors auto, STL containers, and smart pointers. Competitive Programming adds fast I/O and terser output. Embedded/Constrained uses explicit fixed-width types and flags exceptions for removal. Teaching/Verbose keeps every comment and spells out types instead of using auto.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
