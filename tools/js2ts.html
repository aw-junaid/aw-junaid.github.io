✦ How This Tool Works

How does type inference work without a JS type checker?

The converter reads literal values, default parameters, return statements, and any JSDoc @param/@returns tags you've written to guess a type per variable, parameter, or return value. When it truly can't tell, it falls back to the configured fallback type (unknown or any) and logs a note so you can double-check it.

Why does it flag things instead of just converting them?

JavaScript's dynamic-typing escape hatches — typeof-branching logic, reassigning a variable to a different shape, eval, dynamic obj[key] access, and the arguments object — don't have a clean 1:1 TypeScript equivalent that preserves both safety and behavior. Rather than silently emitting any everywhere, the tool flags these constructs in the Conversion Notes tab for manual review.

How are object literals turned into interfaces?

When "Object literal shapes" is set to interface, a repeated or clearly-structured object literal gets its keys and inferred value types promoted into a named interface in the Generated Types tab, and the original literal is annotated with that interface name. Switch to type alias or inline object type if you'd rather not generate named interfaces.

What's the difference between the module output formats?

ESM rewrites require(...) calls into import statements and module.exports/exports.x into export default/named exports — the modern standard for new TypeScript code. Keep CommonJS leaves your existing require/module.exports structure untouched, useful for a Node codebase not yet ready to switch module systems.

Does it handle strictNullChecks-style typing?

Yes — parameters with a default value are marked optional (?), variables first assigned null and later reassigned get a T | null union, guarded property-access chains (a && a.b && a.b.c) collapse into ?., and the common x || fallback default pattern can be rewritten to ?? so it only overrides null/undefined, not falsy values like 0 or "".

Can I convert multiple files at once?

Yes — upload or drag in several .js/.mjs/.cjs files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .ts files into one archive.

What do the built-in presets change?

Strict Modern TS favors ESNext, unknown over any, and generated interfaces. Node.js Backend keeps CommonJS module semantics with ES2020 output. React/Frontend targets ESM with readonly props for component-shaped objects. Gradual Migration relaxes strictness and skips risky rewrites, aimed at a large codebase migrating incrementally.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
