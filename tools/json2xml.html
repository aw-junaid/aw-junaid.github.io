✦ How This Tool Works

How are JSON arrays turned into XML?

XML has no native array type, so you choose the shape: "Repeat parent tag" outputs one sibling element per item under the same tag name (feed/RSS style), "Wrap in container" nests each item inside an extra wrapper element with item tags, and "Indexed elements" numbers each item (item-0, item-1…) so order is unambiguous even after re-parsing.

How do I get XML attributes instead of child elements?

Prefix a JSON key with your attribute-key character (default @), e.g. "@id": 42. With that setting on, it's written as an attribute on the parent element rather than a nested tag. Combine it with the #text key to give an element both attributes and inline text content.

What does CDATA wrapping do?

Turning it on wraps string values in <![CDATA[ … ]]> so characters like <, >, and & are preserved literally instead of being entity-escaped. Leave it off for stricter, more portable XML.

What does the Tree View and Inferred XSD show?

Tree View lays out the parsed JSON as an indented outline of keys, types, and values so you can scan deeply nested structures at a glance. Inferred XSD generates a best-effort XML Schema (element names, types, and repeating sequences) from your data — a useful starting point, not a substitute for a hand-written schema.

Can I convert multiple files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .xml files into one archive.

What does Strict Mode change?

With Strict Mode on, any parse error stops conversion and shows the exact line and column of the problem. With it off, the parser still reports the error but the editor won't visually flag partial output — useful when iterating on a file you know is incomplete.

What do Presets and Export/Import Config do?

Presets instantly apply a bundle of settings tuned for a use case (spec-clean strict XML, SOAP-style attributes and namespaces, feed-style repeated tags, minified output). Export Config saves your exact settings as a JSON file your team can share and re-import for consistent output.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
