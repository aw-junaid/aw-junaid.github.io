✦ How This Tool Works

How do I turn flat columns into nested YAML?

Name your columns using dot notation, like address.city or owner.contact.email, and turn on "Expand dot notation." Each dot becomes a nesting level, so a spreadsheet export can produce config-shaped YAML without editing the source file.

How do repeated columns become arrays?

Columns named with bracket suffixes, like tags[0], tags[1], tags[2], are collapsed into a single tags array in index order when "Expand bracket notation" is on — useful for exporting multi-value fields from a flat spreadsheet.

What's the difference between List, Keyed, and Grouped output?

List (the default) writes every row as an item in a YAML sequence. Keyed mode uses one column's value as the top-level map key for each record — handy for inventories keyed by hostname or ID. Grouped mode buckets records into arrays under each distinct value of a chosen column.

How are empty cells and null-like values handled?

Cells that exactly match one of your null-like tokens (like N/A or -) and genuinely empty cells are both routed through the same "Empty value handling" setting — converted to null, an empty string, or dropped from the record entirely.

Block style vs. Flow style — which should I use?

Block style is the familiar indented YAML most tools and humans expect. Flow style packs the same data into JSON-like { } / [ ] braces on fewer lines — valid YAML, but denser and better suited to short config snippets than long documents.

Can I convert multiple files at once?

Yes — upload or drag in several .csv files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .yaml files into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
