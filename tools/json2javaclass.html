✦ How This Tool Works

How does it decide between a primitive, a wrapper type, and BigDecimal?

Every occurrence of a key across sibling objects is sampled. If a field is ever seen as null, it can't be a raw Java primitive (primitives have no null state), so it's automatically forced to a wrapper type (Integer, Boolean, etc.) and flagged. Fields that mix whole numbers and decimals across samples widen to double/Double, or to BigDecimal if that setting is on — useful for money fields where float rounding errors are unacceptable.

Why does it rename my JSON keys?

JSON commonly uses snake_case or kebab-case, which isn't idiomatic Java (fields are conventionally camelCase). With "camelCase" selected, fields are renamed and the original key is preserved via @JsonProperty("original_key") (Jackson) or @SerializedName("original_key") (Gson), so serialization round-trips correctly without you tracking the mapping by hand.

What's the difference between the class styles?

POJO gives mutable fields with getters/setters. Immutable POJO uses private final fields set once in the constructor, with getters only. Java Record (16+) is the language's own compact immutable data carrier — one line per class, with equals/hashCode/toString generated by the compiler. Lombok styles (@Data/@Value) remove the boilerplate entirely via annotation processing, at the cost of a build-time dependency.

How are duplicate/near-duplicate object shapes handled?

With "Deduplicate structurally identical classes" on, two JSON objects (even at different paths) that produce the same field names and types are collapsed into a single generated class instead of emitting near-identical classes twice — common in API responses with repeated address/contact/money shapes.

Does it detect dates, UUIDs, and enums automatically?

Yes, each independently toggleable. ISO 8601 strings become java.time.LocalDate/Instant/LocalDateTime (never the legacy java.util.Date); RFC 4122 strings become java.util.UUID; and string fields with a small, repeated set of values across an array (e.g. a status field) can be promoted to a generated Java enum with proper Jackson serialization mapping.

Can I convert multiple JSON files at once?

Yes — upload or drag in several .json files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .java files into one archive.

What do the built-in presets change?

API Response favors Jackson annotations, wrapper types, and ignoring unknown properties for resilience to schema drift. Immutable Value Object adds final fields and a builder. Java Record uses the compact 16+ syntax. Lombok trims boilerplate via @Data/@Builder. Config/Internal POJO turns off annotations and prefers plain primitives for internal-only objects.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
