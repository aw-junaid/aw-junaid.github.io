✦ How This Tool Works

How are repeated XML tags turned into arrays?

When two or more sibling elements share the same tag name, they're automatically collapsed into a JSON array in document order. Turn on "Force arrays for repeated tags" if you want that same key to always be an array, even on documents where only one sibling happens to appear.

How do XML attributes become JSON?

With "XML attributes → prefixed keys" on, an attribute like id="42" is written as "@id": "42" on the same object as that element's children — using whatever prefix character you set. Combine it with the text-content key so an element can carry attributes, children, and inline text at once.

What does CDATA unwrapping do?

Turning it on merges <![CDATA[ … ]]> content straight into the text value like any other text node. Leave it off only if you need to detect CDATA sections separately — this tool treats their content as plain text either way.

What does the Tree View and Inferred Schema show?

Tree View lays out the converted JSON as an indented outline of keys, types, and values so you can scan deeply nested results at a glance. Inferred Schema generates a best-effort JSON Schema (types, object properties, array item shapes) from your data — a useful starting point, not a substitute for a hand-written schema.

Can I convert multiple files at once?

Yes — upload or drag in several .xml files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .json files into one archive.

What does Strict Mode change?

With Strict Mode on, any malformed XML stops conversion and shows the parser's full error detail. With it off, the same error is still shown, but the input editor won't be visually flagged — useful while iterating on a document you know is incomplete.

What do namespace options do?

"Strip namespace prefixes" removes the part before the colon in tag and attribute names (so soap:Body becomes Body). "Keep xmlns declarations" controls whether xmlns / xmlns:* attributes are kept as ordinary keys or dropped from the output.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
