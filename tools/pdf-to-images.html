✦ How This Tool Works

What DPI should I actually use?

96 DPI is fine for viewing on screen or dropping into a slide deck. Use 150-300 DPI for anything that will be printed. 600 DPI is worth the bigger file size only when the images feed into OCR or you need to zoom into fine text or diagrams.

Why does JPEG need a background fill color?

JPEG has no transparency channel, so any part of a page the PDF leaves unpainted renders as solid black by default. Filling the canvas with white (or any color you choose) before rendering avoids that black-edge artifact entirely.

What does auto-crop margins actually do?

It scans each rendered page for the bounding box of non-background pixels and trims the uniform border around it, leaving your chosen padding. It's built for scanner batches where every page has the same wide, empty margin you don't want in the final image.

How do I export only some pages?

Type a range like 1-3,5,8-10 into Page Selection and hit "Apply Range to Picker" — it checks those boxes in the thumbnail grid below. You can then click individual thumbnails to fine-tune the selection by hand before converting.

ZIP archive or individual files — which should I pick?

ZIP is easiest for a multi-page export since it's one download and keeps everything together. Individual files are useful when you only exported one or two pages, or you want to drag specific pages straight into another app.

Is anything uploaded to a server?

No. The file you add is read and rendered locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
