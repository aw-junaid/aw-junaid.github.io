✦ How This Tool Works

Will minifying break my XML?

No — minifying only removes bytes that don't change meaning: insignificant whitespace, comments, and redundant declarations. Text content, attribute values, element order, and namespace bindings that are actually used are all preserved exactly.

Why does some whitespace survive even with stripping on?

Whitespace inside an element marked xml:space="preserve", or inside a tag you've listed in "preserve whitespace inside these tags", is left untouched on purpose — that's how formats like DocBook, XLIFF, and SVG mark text where line breaks and indentation are meaningful.

What counts as a "redundant" vs "unused" namespace?

Redundant means a child element re-declares an xmlns that an ancestor already declared with the identical URI — safe to drop since the binding is already in scope. Unused means the namespace URI never appears on any element or attribute in that subtree at all, so the declaration itself is dead weight — useful for cleaning up XML generated by tools that declare namespaces defensively.

What happens to my DOCTYPE and internal subset?

You can choose to keep or remove the DOCTYPE line. Note this tool reproduces the DOCTYPE's name and PUBLIC/SYSTEM identifiers, but does not reconstruct a custom internal subset (inline entity/attlist definitions) — if your document relies on one, keep a backup of the original.

Should I keep or convert CDATA sections?

Keep them if the wrapped content contains characters like unescaped < or & that would otherwise need escaping — common in embedded HTML or code snippets. Converting to escaped text usually saves a few bytes on short, simple values and keeps the whole document in one consistent style.

Why self-close empty elements?

<tag></tag> and <tag/> are exactly equivalent in XML, so collapsing to the self-closing form is a pure size win with zero risk to how the document is interpreted downstream.

What is the Namespace Map for?

Before trusting a minified config or SOAP payload, it helps to confirm which xmlns declarations survived. The Namespace Map lists every declared namespace in document order and marks the ones this conversion dropped, so you can double-check nothing you actually rely on was removed.

Can I convert multiple files at once?

Yes — upload or drag in several .xml files and each becomes a tab above the editor. "Download All (.zip)" minifies every loaded file with your current settings and bundles the results into one archive. Nothing is uploaded to a server; everything runs locally in your browser.
