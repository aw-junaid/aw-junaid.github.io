✦ How This Tool Works

What markdown flavor does it support?

Standard Markdown plus optional GitHub Flavored Markdown — tables, task lists, and strikethrough — toggled from the settings panel.

Is the HTML output safe to publish?

With "Sanitize HTML" on, script tags and other unsafe raw HTML embedded in your markdown are stripped before rendering or export. The live preview is always sandboxed and sanitized regardless of that setting.

What do Presets and Export/Import Config do?

Presets instantly apply a bundle of settings tuned for a use case (blog, docs, email-safe newsletter, minimal). Export Config saves your exact settings as a JSON file your team can share and re-import for consistent output.

Can I convert multiple files at once?

Yes — upload or drag in several .md files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting HTML files into one archive.

Does it support math and diagrams?

Yes. Turn on "Math rendering" to render $inline$ and $$block$$ LaTeX via KaTeX, and "Mermaid diagrams" to turn fenced ```mermaid blocks into flowcharts, sequence diagrams, and more. Both always render in the live Preview; enable "Full HTML document" too so the exported file includes the required libraries.

What does the code language label do?

When on, every fenced code block gets a small header showing its detected language (e.g. "js", "python") plus a one-click Copy button — handy for docs and tutorials where readers need to grab a snippet quickly.

What does "Full HTML document" add?

It wraps your converted content with a complete <html><head><body> structure, your document title, meta description, language attribute, base styling, any custom CSS, and the CDN links/scripts needed for syntax highlighting, math, or diagrams — so the downloaded file opens as a fully working standalone page.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
