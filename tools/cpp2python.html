✦ How This Tool Works

Is this a real C++ compiler front-end?

No — it's a heuristic, pattern-based translator, the same approach most browser-based code converters use. It handles the C++ patterns that show up constantly in real code (loops, STL containers, I/O, classes) very well, but it doesn't build a full AST or type-check your program. Always read and test the Python it produces.

What ends up in the Warnings tab?

Anything the converter can't translate safely without changing behavior: raw pointers and references, templates, manual new/delete, goto, operator overloading, and multiple inheritance. Each warning includes the offending snippet so you know exactly what to revisit by hand.

How are C-style for-loops handled?

When a loop matches the common "for (int i = 0; i < n; i++)" counting shape, it's rewritten as "for i in range(...)" with the correct start, stop, and step — including decrementing loops. Loops that don't match a simple counter (multiple variables, complex conditions) fall back to an equivalent while-loop instead of being guessed at.

How is switch/case converted?

Each switch block becomes an if/elif/else chain. Case labels with no code between them (fallthrough) are merged into a single condition with "or", and "break;" is simply dropped since Python's elif chain doesn't fall through by default.

What happens to pointers and references?

Python doesn't have raw pointers, so "int*", "int&", "new", and "delete" are stripped from the type/expression and the line is flagged in Warnings — the resulting variable is left as a plain Python reference, which is correct for objects/containers but not for pointer arithmetic or manual memory tricks.

Can I convert multiple files at once?

Yes — upload or drag in several .cpp/.h files and each becomes a tab above the editor. "Download All (.zip)" converts every loaded file with your current settings and bundles the resulting .py files into one archive.

Is anything uploaded to a server?

No. Files you upload are read locally in your browser and the conversion happens entirely client-side — nothing is sent anywhere. Your draft and settings only persist in this browser's local storage.
