✦ How This Tool Works

What problem does this actually solve?

Classful addressing (Class A–E) predates CIDR and is no longer how the internet actually routes traffic, but it's still the basis for default subnet masks in exam curricula, legacy documentation, and quick mental math about how "big" an address block historically was. This tool removes the manual step of checking the first octet against a memorized range table.

How is the class actually decided?

Purely by the leading bits of the first octet: 0xxxxxxx is Class A, 10xxxxxx is Class B, 110xxxxx is Class C, 1110xxxx is Class D (multicast), and 1111xxxx is Class E (reserved/experimental). Everything else on this page — default mask, host counts, network math — follows from that one classification.

Why does 127.0.0.0 show as Class A but isn't usable?

127.0.0.0/8 falls squarely inside the Class A first-octet range (0–127) by the numbers, but it was carved out specifically for loopback traffic and was never assigned to hosts on a network. The Special-Use overlay flags this so the classful math doesn't mislead you into thinking it's an ordinary Class A network.

Does Class D or E have a subnet mask?

No. Multicast (Class D) and reserved (Class E) space was never divided into networks and hosts the way A/B/C were, so there's no default mask to compute network/broadcast/usable-host figures from. The tool shows "n/a" for those fields rather than a misleading number.

What does the "custom prefix override" actually change?

By default, network/broadcast/host math uses the class's traditional mask (/8, /16, or /24). Turning on the override lets you apply any CIDR prefix instead, so you can see exactly how modern subnetting — say, splitting a Class C-range block into /27s — departs from what classful addressing would have assumed.

Is anything sent to a server?

No, with one exception: the "Classify My Public IP" button is opt-in and calls a third-party API (ipify.org) to look up your public IP. Everything else — parsing, classification, bit math, batch auditing — runs entirely in your browser. Your draft and settings only persist in this browser's local storage.
