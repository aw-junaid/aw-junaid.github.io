✦ How This Tool Works

What's the difference between the Info dictionary and XMP?

The Info dictionary is the classic Title/Author/Producer block every PDF viewer reads. XMP is a separate XML packet many editors also embed — it can repeat the same fields, or carry extra ones the Info dictionary doesn't show, including software history and sometimes location data.

Why would I strip metadata before sharing a file?

The Author and Creator fields often leak a real name, a company name, or the exact software (and version) used to make the file — information you may not want attached to a public download, a legal filing, or a leaked draft.

Does editing metadata change how the PDF looks?

No. Edit and Strip modes only touch the document's metadata and info dictionary — every page, image, and piece of text is copied through untouched into the rebuilt file.

What do the structure flags mean?

They tell you whether the file has fillable form fields, embedded file attachments, an outline/bookmark tree, or embedded JavaScript — all things that can carry hidden behavior or data beyond the visible pages.

Can I check many PDFs at once?

Yes — add several files, then use "Apply to All (batch)" to run the same edit or strip settings across every loaded file. Export the findings for all of them as JSON or CSV from the Results tab.

Is anything uploaded to a server?

No. Every file you add is read and processed locally in your browser — nothing is sent anywhere. Reload the page and everything is cleared, except your settings, which are remembered for next time.
